## I. THÔNG TIN CHUNG & MỤC TIÊU KSA

### 1. Trọng tâm học phần
Tập trung vào **Kỹ thuật Code Chuyên nghiệp, Phương pháp Vibe Coding, Kỹ năng Quản lý Code (Git/GitHub)** và **Phân tích Giải pháp Phần mềm (Desktop GUI & Web Dashboard)**.

### 2. Mục tiêu KSA (Knowledge - Skills - Attitude)
* **Knowledge (Kiến thức):** Nắm vững Cấu trúc dữ liệu nâng cao (List, Dictionary, Tuple, Set), Thao tác Tệp (File I/O: JSON, CSV, TXT), Kiến trúc Module/Package và Cụm lệnh Git chuyên nghiệp.
* **Skills (Kỹ năng):**
  * **Vibe Coding:** Sử dụng AI làm "Developer với tay", ra lệnh bằng ngôn ngữ tự nhiên để sinh code, xử lý giao diện và phát triển phần mềm tốc độ cao.
  * **Quản lý Mã nguồn:** Làm chủ quy trình làm việc với Git/GitHub (Branching, Commit, Merge, Resolve Conflicts, Pull Request).
  * **Phân tích Giải pháp:** Phân tích bài toán thực tế thành luồng chức năng và thiết kế giao diện đồ họa (CustomTkinter GUI / Streamlit Web Dashboard).
* **Attitude (Thái độ):** Đột phá về năng suất lập trình nhờ AI nhưng giữ nguyên kỷ luật quản lý mã nguồn chặt chẽ.

## II. KẾ HOẠCH GIẢNG DẠY CHI TIẾT (12 BUỔI × 5 TIẾT)

> **Phương pháp Vibe Coding:** 1 tiết định hướng kỹ thuật/giải pháp + 4 tiết thực chiến "giao tiếp với AI để tạo dựng sản phẩm".

| **1** | **Tư duy Vibe Coding & Git/GitHub Baseline** | Thiết lập môi trường Vibe Coding (Cursor/VS Code + Copilot); Tạo Git Repo, thực hành `git add, commit, push`. | Thiết lập Context cho AI hiểu cấu trúc thư mục dự án; Quản lý phiên bản mã nguồn. |
| **2** | **Cấu trúc dữ liệu Nâng cao (List, Dict, Set, Tuple)** | Biến đổi dữ liệu phức tạp: Quản lý kho hàng, danh bạ; Xử lý List Comprehension & Lambda. | Ra lệnh cho AI tối ưu hóa thao tác duyệt/lọc dữ liệu bằng List/Dict Comprehension. |
| **3** | **Thao tác Tệp Dữ liệu (File I/O: TXT, CSV, JSON)** | Đọc/Ghi dữ liệu ra file; Lưu cấu hình ứng dụng (JSON); Nhập/Xuất báo cáo (CSV). | Yêu cầu AI xử lý các ngoại lệ file hỏng, thiếu file bằng `try-except-finally`. |
| **4** | **Phân tích Vấn đề & Thiết kế Giải pháp Phần mềm** | Phân tích bài toán thực tế thành luồng chức năng (Functional Flow); Thiết kế sơ đồ kiến trúc module phần mềm. | Dùng AI đóng vai Software Architect để phản biện và đề xuất giải pháp kiến trúc. |

| **8** | **Xây dựng Giao diện Đồ họa (Desktop GUI)** | Thiết kế ứng dụng Desktop (CustomTkinter/PyQt): Form nhập liệu, bảng dữ liệu (Treeview), sự kiện (Events). | Sử dụng AI để "vẽ" giao diện GUI bằng code Python từ mô tả layout tự nhiên. |
