2.3. Công nghệ sử dụng

  • Ứng dụng di động: React Native + Expo (Expo Router, TypeScript), TanStack Query, Zustand, React Hook Form + Zod, Expo SecureStore, EAS Build.
  • Backend: Node.js/NestJS, Socket.IO; truy cập CSDL chỉ qua stored procedure bằng thư viện mssql.
  • CSDL: Microsoft SQL Server, triển khai trên Windows Server do Khoa cấp. Ứng dụng không có CSDL trên thiết bị.
  • Công cụ AI: Google Antigravity, GitHub Copilot Chat.
  • Công cụ thiết kế: Figma, draw.io, dbdiagram.io.

💡 3. Cách học & quy tắc làm việc ▼

🧩 Học theo dự án (PBL)

Nhóm 4–5 sinh viên chọn một đề tài và phát triển suốt 4 sprint. Khuyến khích dùng chung đề tài và backend với môn Lập trình ứng dụng Web. Cuối mỗi sprint (buổi 03, 06, 09) nhóm demo sản phẩm và rút kinh nghiệm.

🤖 Vibe coding có kiểm soát

  • Được dùng Google Antigravity và GitHub Copilot Chat để sinh mã, nhưng mỗi Pull Request phải kèm prompt chính đã dùng (ghi trong PROMPTS.md).
  • Không hiểu thì không merge: người tạo PR phải giải thích được mọi đoạn mã khi được hỏi.
  • Mỗi nhóm có AGENTS.md và .github/copilot-instructions.md mô tả kiến trúc và quy ước của dự án để AI sinh mã nhất quán.
  • Commit nhỏ, mỗi tính năng một nhánh, review chéo trước khi merge. Lịch sử commit/PR là căn cứ đánh giá vai trò cá nhân.

🗄️ Quy tắc dữ liệu

Dữ liệu chỉ nằm trên SQL Server. Backend chỉ gọi stored procedure có tham số bằng thư viện mssql; không viết câu SQL trực tiếp trong mã backend và không dùng ORM để sinh truy vấn.

Laptop cài Node.js (bản LTS), VS Code, Git; tài khoản GitHub; điện thoại Android có cài ứng dụng Expo Go (hoặc Android Studio để chạy emulator).
