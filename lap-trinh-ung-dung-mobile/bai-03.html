BÀI 03 - Điều hướng với Expo Router (5 tiết: 1 LT / 4 TH)

Trên web, người dùng bấm link và thanh địa chỉ đổi URL. Trên điện thoại không có thanh địa chỉ, nhưng có nút Back, có thanh tab và có cử chỉ vuốt. Ứng dụng của bạn nên tổ chức các màn hình thế nào để người dùng không bị "lạc"?

Mục tiêu: Giải thích được mô hình điều hướng trên mobile (stack, tab, modal); xây dựng được điều hướng theo file bằng Expo Router; phác thảo được sơ đồ luồng màn hình và ERD sơ bộ từ các chức năng.

Nội dung:

  • Ý chính 1 - Điều hướng trên mobile: stack lịch sử màn hình, nút Back của Android, tab, modal.
  • Ý chính 2 - Expo Router: mỗi file trong app/ là một màn hình; _layout.tsx khai báo Stack hoặc Tabs; nhóm route (tabs).
  • Ý chính 3 - Route động và tham số: [id].tsx, useLocalSearchParams, chuyển màn hình bằng Link và router, deep link.
  • Ý chính 4 - Từ màn hình đến dữ liệu: mỗi màn hình cần thực thể nào; phác ERD sơ bộ làm đầu vào cho thiết kế CSDL SQL Server ở bài 05.

Kết quả cần đạt: Ứng dụng có đủ điều hướng với dữ liệu giả, nút Back của Android hoạt động đúng; nhóm hoàn thành Checkpoint Sprint 1 kèm sơ đồ luồng màn hình và ERD sơ bộ.

CLO liên quan: CLO1, CLO2, CLO3.

📚 2. Học liệu chính ▼

2.1. Điều hướng trên mobile khác web thế nào?

  • Stack: màn hình mới được "đặt chồng" lên màn hình cũ. Nút Back của Android hoặc cử chỉ vuốt sẽ gỡ màn hình trên cùng. Ví dụ: Danh sách món → Chi tiết món.
  • Tab: thanh điều hướng cố định ở cuối màn hình cho các khu vực chính. Ví dụ: Trang chủ, Giỏ hàng, Đơn hàng, Tài khoản.
  • Modal: màn hình trượt lên che màn hình hiện tại cho một tác vụ ngắn, đóng xong quay lại đúng chỗ cũ. Ví dụ: xác nhận đặt hàng.

Một ứng dụng thật thường lồng các kiểu này: Stack gốc chứa nhóm Tab, mỗi tab lại có thể mở thêm màn hình chi tiết.

2.2. Expo Router: điều hướng theo file

Expo Router dùng cấu trúc thư mục app/ làm bản đồ điều hướng, tương tự cách Next.js dùng thư mục cho web. Dự án tạo bằng create-expo-app đã có sẵn Expo Router.

app/
├── _layout.tsx          # Stack gốc của toàn ứng dụng
├── (tabs)/
│   ├── _layout.tsx      # Thanh tab
│   ├── index.tsx        # Tab Trang chủ  →  /
│   ├── cart.tsx         # Tab Giỏ hàng   →  /cart
│   ├── orders.tsx       # Tab Đơn hàng   →  /orders
│   └── account.tsx      # Tab Tài khoản  →  /account
├── product/
│   └── [id].tsx         # Chi tiết món   →  /product/12
└── confirm.tsx          # Modal xác nhận →  /confirm

Tên thư mục trong ngoặc như (tabs) là nhóm route: dùng để gom màn hình chung một layout, không xuất hiện trong đường dẫn.

// app/_layout.tsx
import { Stack } from 'expo-router';

export default function RootLayout() {
  return (
    <Stack>
      <Stack.Screen name="(tabs)" options={{ headerShown: false }} />
      <Stack.Screen name="product/[id]" options={{ title: 'Chi tiết món' }} />
      <Stack.Screen name="confirm" options={{ presentation: 'modal', title: 'Xác nhận' }} />
    </Stack>
  );
}

// app/(tabs)/_layout.tsx
import { Tabs } from 'expo-router';

export default function TabLayout() {
  return (
    <Tabs>
      <Tabs.Screen name="index" options={{ title: 'Trang chủ' }} />
      <Tabs.Screen name="cart" options={{ title: 'Giỏ hàng' }} />
      <Tabs.Screen name="orders" options={{ title: 'Đơn hàng' }} />
      <Tabs.Screen name="account" options={{ title: 'Tài khoản' }} />
    </Tabs>
  );
}

2.3. Route động, tham số và deep link

File product/[id].tsx phục vụ mọi đường dẫn dạng /product/1, /product/2… Màn hình đọc tham số bằng useLocalSearchParams.

// app/product/[id].tsx
import { useLocalSearchParams, router } from 'expo-router';
import { View, Text, Pressable } from 'react-native';

export default function ProductDetail() {
  const { id } = useLocalSearchParams<{ id: string }>();

  return (
    <View>
      <Text>Món số {id}</Text>
      <Pressable onPress={() => router.push('/confirm')}>
        <Text>Đặt ngay</Text>
      </Pressable>
    </View>
  );
}

// Từ màn hình danh sách: mở chi tiết món
import { Link } from 'expo-router';
<Link href={`/product/${item.id}`}>Xem chi tiết</Link>
  • router.push() thêm màn hình vào stack; router.back() quay lại; router.replace() thay màn hình hiện tại (dùng khi đăng nhập xong, để Back không quay về màn hình đăng nhập).
  • Deep link: khai báo "scheme": "lhufood" trong app.json; khi đó đường dẫn lhufood://product/12 mở thẳng màn hình chi tiết món 12. Bài 09 dùng tính năng này để bấm thông báo mở đúng đơn hàng.

2.4. Từ màn hình đến dữ liệu: sơ đồ luồng màn hình và ERD sơ bộ

Sơ đồ luồng màn hình vẽ các màn hình và mũi tên chuyển giữa chúng. Nó giúp nhóm thống nhất cấu trúc thư mục app/ trước khi viết mã.

Mỗi màn hình hiển thị hoặc tạo ra dữ liệu. Liệt kê dữ liệu đó, ta có danh sách thực thể và quan hệ, tức là ERD sơ bộ. Bài 05 sẽ hoàn thiện ERD thành CSDL SQL Server thật và viết stored procedure.

Màn hình LHU FoodThực thể cần có
Trang chủ, Danh mụcDanh mục (Categories), Món (Products)
Giỏ hàng, Xác nhậnMón, Người dùng (Users)
Đơn hàng, Chi tiết đơnĐơn hàng (Orders), Chi tiết đơn (OrderItems)

Quan hệ sơ bộ: một Danh mục có nhiều Món (1-n); một Người dùng có nhiều Đơn hàng (1-n); Đơn hàng và Món là quan hệ n-n, tách qua bảng Chi tiết đơn. Vẽ bằng dbdiagram.io hoặc draw.io.

💡 3. Hoạt động & Thực hành trên lớp ▼

🧑‍🏫 Thực hành có hướng dẫn (2 tiết): Điều hướng LHU Food

  1. Tổ chức lại thư mục app/ theo cây ở mục 2.2; chuyển các màn hình đã làm ở bài 02 vào đúng vị trí.
  2. Khai báo Stack gốc và thanh 4 tab; thêm biểu tượng cho tab.
  3. Tạo product/[id].tsx; bấm món ở Trang chủ mở đúng chi tiết món (dữ liệu giả trong data/products.ts).
  4. Tạo modal confirm.tsx mở từ nút "Đặt ngay"; đóng modal quay lại chi tiết món.
  5. Kiểm tra nút Back của Android ở từng màn hình.
  6. Vẽ sơ đồ luồng màn hình và ERD sơ bộ của LHU Food, lưu vào docs/.

✍️ Thực hành không hướng dẫn (1,5 tiết): Luồng Danh mục

Thêm luồng Danh mục → Danh sách món theo danh mục → Chi tiết món. Danh sách món dùng route động theo mã danh mục và hiển thị tên danh mục trên thanh tiêu đề.

Hoàn thành khi: mở đúng danh sách cho từng danh mục; tiêu đề đổi theo danh mục; nút Back của Android quay lại đúng từng bước; không có màn hình nào bị lặp trong stack.

🆘 4. Góc trợ giúp và mở rộng ▼

Màn hình mới không hiện: file phải nằm trong app/ và có export default một component. Kiểm tra tên trong Stack.Screen name khớp đúng đường dẫn file.

Thanh tiêu đề hiện hai lần: màn hình nằm trong Tabs nhưng Stack gốc cũng hiện header; thêm headerShown: false cho (tabs) ở Stack gốc.

Back quay về màn hình đăng nhập sau khi đã đăng nhập: dùng router.replace() thay cho router.push().

Kiến thức mở rộng: Tìm hiểu typed routes của Expo Router để TypeScript báo lỗi khi gõ sai đường dẫn.

Tự đánh giá: Nhìn vào thư mục app/ của nhóm, một bạn mới có đoán được ứng dụng có những màn hình nào và đi từ đâu tới đâu không?
