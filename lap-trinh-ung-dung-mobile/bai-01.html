BÀI 01 - Tổng quan phát triển ứng dụng di động & khởi động dự án (5 tiết: 2 LT / 3 TH)

Bạn đã viết được web app bằng React. Vậy cần học thêm gì để cùng một nhóm kỹ năng đó chạy được trên điện thoại Android, và làm sao để AI giúp bạn nhanh hơn mà không làm bạn mất kiểm soát mã nguồn?

Mục tiêu: So sánh được các hướng phát triển ứng dụng di động; giải thích được kiến trúc React Native và vai trò của Expo; thiết lập được môi trường, quy trình vibe coding và bảng phân vai của nhóm dự án.

Nội dung:

  • Ý chính 1 - Ba hướng phát triển: Native, cross-platform và PWA; vì sao chọn React Native khi đã biết React.
  • Ý chính 2 - Kiến trúc React Native & Expo: Mã JavaScript điều khiển component native; Expo Go, development build và EAS.
  • Ý chính 3 - Từ React web sang React Native: View/Text thay cho thẻ HTML, StyleSheet thay cho file CSS, onPress thay cho onClick.
  • Ý chính 4 - Vibe coding có kiểm soát: AGENTS.md, prompt có ngữ cảnh, review mã AI sinh ra, ghi PROMPTS.md.

Kết quả cần đạt: Sinh viên chạy được ứng dụng Expo đầu tiên trên điện thoại Android, đẩy mã lên GitHub; nhóm có Project Brief, bảng phân vai và repo chung.

CLO liên quan: CLO1, CLO4.

📚 2. Học liệu chính ▼

2.1. Ba hướng phát triển ứng dụng di động

Vì sao chọn React Native? Bạn đã quen React: component, props, state, hook. React Native giữ nguyên cách tư duy đó, chỉ thay "đích hiển thị" từ trình duyệt sang giao diện native của điện thoại.

2.2. React Native hoạt động thế nào? Expo giúp gì?

  • React Native: mã JavaScript/TypeScript của bạn mô tả giao diện bằng component; React Native chuyển chúng thành view native của Android/iOS. Một <Text> trên Android là một TextView thật, không phải một trang web.
  • New Architecture: các phiên bản React Native hiện nay dùng kiến trúc mới (JSI, Fabric, TurboModules), cho phép JavaScript gọi mã native trực tiếp và nhanh hơn.
  • Expo: bộ công cụ và thư viện xây trên React Native, được tài liệu chính thức của React Native khuyến nghị để bắt đầu dự án mới.
    • Expo Go: ứng dụng trên điện thoại để chạy thử dự án ngay, không cần build.
    • Development build: bản app riêng của bạn, dùng khi cần thư viện native mà Expo Go không có.
    • EAS (Build/Update): dịch vụ build file cài đặt (APK/AAB) và cập nhật ứng dụng qua mạng.

💡 Trong học phần: Android là nền tảng bắt buộc; iOS là phần mở rộng. Mỗi sinh viên tự đăng ký tài khoản Expo miễn phí. Gói miễn phí giới hạn số lượt build, nên khi phát triển hãy dùng Expo Go, chỉ build APK khi cần nộp.

2.3. Từ React web sang React Native

React webReact NativeGhi chú
<div><View>Khung chứa, mặc định xếp theo cột
<p>, <span><Text>Mọi chữ bắt buộc nằm trong <Text>
<img><Image>Ảnh từ mạng cần khai báo kích thước
<button onClick><Pressable onPress>Sự kiện chạm thay cho click chuột
File CSS, classNameStyleSheet.create, styleViết bằng JavaScript, tên thuộc tính dạng camelCase, không kế thừa như CSS

💡 Ví dụ: thẻ món ăn của LHU Food.

import { View, Text, Pressable, StyleSheet } from 'react-native';

export function ProductCard({ name, price, onAdd }) {
  return (
    <View style={styles.card}>
      <Text style={styles.name}>{name}</Text>
      <Text>{price.toLocaleString('vi-VN')} đ</Text>
      <Pressable style={styles.button} onPress={onAdd}>
        <Text style={styles.buttonText}>Thêm vào giỏ</Text>
      </Pressable>
    </View>
  );
}

const styles = StyleSheet.create({
  card: { padding: 16, borderRadius: 12, backgroundColor: '#fff' },
  name: { fontSize: 18, fontWeight: 'bold' },
  button: { marginTop: 8, padding: 10, borderRadius: 8, backgroundColor: '#013D88' },
  buttonText: { color: '#fff', textAlign: 'center' },
});

Hãy để ý: cách viết component, props và hàm xử lý giống hệt React web. Thứ thay đổi chỉ là tên component và cách viết style.

2.4. Vibe coding có kiểm soát

Vibe coding là cách lập trình trong đó bạn mô tả điều mình muốn bằng ngôn ngữ tự nhiên và để AI (Google Antigravity, GitHub Copilot Chat) sinh mã. AI viết nhanh, nhưng người chịu trách nhiệm về mã vẫn là bạn.

  1. Cho AI ngữ cảnh: file AGENTS.md (và .github/copilot-instructions.md cho Copilot) mô tả dự án, thư viện được dùng, quy ước đặt tên.
  2. Prompt cụ thể: nêu màn hình nào, dữ liệu gì, tiêu chí hoàn thành ra sao.
  3. Đọc và chạy thử mã AI sinh ra; sửa chỗ sai thay vì chấp nhận nguyên văn.
  4. Ghi lại prompt chính vào PROMPTS.md kèm nhận xét: mã dùng được tới đâu, phải sửa gì.
  5. Không hiểu thì không merge: trước khi gộp vào nhánh chính, bạn phải giải thích được từng dòng.

💡 Ví dụ AGENTS.md rút gọn:

# LHU Food - Quy ước dự án
- Ứng dụng React Native + Expo, TypeScript, điều hướng bằng Expo Router (thư mục app/).
- Component dùng chung đặt trong components/, mỗi file một component, tên PascalCase.
- Style dùng StyleSheet.create; màu và khoảng cách lấy từ constants/theme.ts.
- Không thêm thư viện mới khi chưa hỏi nhóm.
- Chuỗi hiển thị bằng tiếng Việt có dấu.

2.5. Dự án PBL và phân vai trong nhóm

Mỗi nhóm 4–5 sinh viên phát triển một ứng dụng suốt 4 sprint. Khuyến khích chọn cùng đề tài với môn Lập trình ứng dụng Web để dùng chung backend NestJS + SQL Server.

  • Project Brief (1 trang): vấn đề cần giải quyết, người dùng, 5–7 tính năng chính, tính năng nào cần realtime.
  • Vai trò gợi ý: mobile UI, mobile logic, backend API, CSDL và stored procedure, kiểm thử và phát hành. Mỗi người có ít nhất một vai chính; nhóm 4 người thì một người kiêm hai vai.

💡 Vì sao phân vai rõ từ buổi đầu? Điểm CLO4 cuối kỳ chấm theo vai trò cá nhân, dựa trên lịch sử commit/PR và phần bạn tự trình bày. Vai trò mơ hồ thì minh chứng cũng mơ hồ.

💡 3. Hoạt động & Thực hành trên lớp ▼

🧑‍🏫 Thực hành có hướng dẫn (1,5 tiết): Khởi tạo LHU Food

  1. Kiểm tra Node.js bản LTS: node -v. Cài Expo Go trên điện thoại Android.
  2. Đăng ký tài khoản Expo miễn phí tại expo.dev.
  3. Tạo dự án: npx create-expo-app@latest lhu-food, sau đó cd lhu-food.
  4. Chạy: npx expo start, quét mã QR bằng Expo Go (điện thoại và laptop cùng mạng Wi-Fi).
  5. Đọc cấu trúc thư mục: app/ (màn hình), components/, assets/, app.json, package.json.
  6. Sửa nội dung màn hình đầu tiên, lưu file và quan sát app cập nhật ngay (Fast Refresh).
  7. Dùng Antigravity hoặc Copilot Chat viết AGENTS.md từ mô tả dự án; tạo repo GitHub và commit đầu tiên.

✍️ Thực hành không hướng dẫn (1 tiết): Thẻ giới thiệu bản thân

Tự tạo một ứng dụng Expo hiển thị thẻ giới thiệu bản thân: ảnh đại diện, họ tên, lớp, 3 kỹ năng, nút "Liên hệ" (bấm vào hiện thông báo bằng Alert).

Hoàn thành khi: chạy được trên điện thoại Android; mã đẩy lên repo GitHub cá nhân; có PROMPTS.md ghi ít nhất 1 prompt đã dùng và nhận xét của bạn.

👥 Thử thách nhóm (0,5 tiết + ở nhà): Khởi động dự án

🆘 4. Góc trợ giúp và mở rộng ▼

Expo Go không mở được dự án: kiểm tra điện thoại và laptop cùng một mạng Wi-Fi. Nếu mạng phòng lab chặn kết nối giữa các máy, chạy npx expo start --tunnel.

Lỗi khi tạo dự án: dùng Node.js bản LTS; xóa thư mục node_modules rồi chạy lại npm install.

Không có điện thoại Android: cài Android Studio, tạo emulator (Device Manager), rồi nhấn phím a trong cửa sổ npx expo start.

Kiến thức mở rộng: Đọc phần "Core Components and Native Components" trong tài liệu React Native để hiểu cách một component được ánh xạ thành view native.

Tự đánh giá: Bạn có giải thích được vì sao chữ đặt trực tiếp trong <View> (không bọc <Text>) sẽ gây lỗi không?
