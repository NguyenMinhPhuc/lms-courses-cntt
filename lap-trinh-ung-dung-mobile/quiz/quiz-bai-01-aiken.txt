Hướng phát triển nào dùng một mã nguồn để chạy trên cả Android và iOS, với giao diện là component native?
A. Native (Kotlin cho Android, Swift cho iOS)
B. Cross-platform như React Native
C. PWA (Progressive Web App)
D. Website responsive thông thường
ANSWER: B

Lý do chính để học phần chọn React Native là gì?
A. React Native không cần lập trình
B. React Native chỉ chạy trên iOS
C. Sinh viên đã biết React nên dùng lại được cách tư duy component, props, state và hook
D. React Native không cần kết nối backend
ANSWER: C

Khi React Native hiển thị một component Text trên Android, kết quả là gì?
A. Một trang web nhúng trong ứng dụng
B. Một view native thật của Android
C. Một hình ảnh tĩnh
D. Một đoạn mã HTML
ANSWER: B

Expo Go dùng để làm gì?
A. Quản lý cơ sở dữ liệu SQL Server
