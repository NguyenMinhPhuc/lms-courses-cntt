## Bài tập hướng dẫn theo dự án LHU Food

**Nhiệm vụ:** dựng bộ khung điều hướng đầy đủ của LHU Food theo danh sách màn hình trong SRS, nối các màn hình đã có, vẽ sơ đồ luồng màn hình và ERD sơ bộ; chuẩn bị demo Checkpoint Sprint 1.

- **Tài liệu dùng kèm:** SRS mục 5.14.1 (màn hình và route), mục 7.1 (các bảng), mục 4.3 (US-C02, US-C06 để dựng khung).
- **User story:** US-G01, US-G03 (điều hướng); khung màn hình cho US-C02, US-C06, US-C13.
- **Thời lượng gợi ý:** 2 tiết trên lớp.

### Chuẩn bị môi trường

```bash
git checkout main && git pull
git checkout -b feature/navigation
npx expo install expo-router react-native-screens react-native-safe-area-context expo-linking expo-constants expo-status-bar
```

Dự án tạo bằng `create-expo-app` phiên bản mới đã có sẵn Expo Router; lệnh trên chỉ cần khi dự án chưa có. Kiểm tra `package.json` có `"main": "expo-router/entry"`.

### Các bước triển khai

**Bước 1. Tạo cây thư mục `app/`** đúng như mục 3.2.2 và bảng màn hình SRS 5.14.1: `(tabs)/index`, `cart`, `orders`, `account`; `product/[id]`, `category/[id]`. Màn hình chưa làm chỉ cần tiêu đề và chữ "Đang xây dựng".

**Bước 2. Layout.** `app/_layout.tsx` là Stack (mục 3.2.3), `app/(tabs)/_layout.tsx` là Tabs có biểu tượng (mục 3.2.4).

**Bước 3. Route động.** Bấm `ProductCard` mở `/product/<id>`; màn hình chi tiết đọc `id` bằng `useLocalSearchParams` và tìm món trong dữ liệu giả; `id` không tồn tại thì hiện "Không tìm thấy món".

**Bước 4. Danh mục.** Bấm một danh mục ở Trang chủ mở `/category/<id>`, đặt tiêu đề màn hình bằng tên danh mục.

**Bước 5. Sơ đồ luồng màn hình.** Vẽ bằng draw.io: mỗi màn hình là một hộp, mũi tên ghi thao tác (bấm thẻ món, bấm tab…), phân biệt tab, stack, modal.

**Bước 6. ERD sơ bộ.** Từ các màn hình, liệt kê thực thể (Categories, Products, Users, Orders, OrderItems) và quan hệ; vẽ ERD sơ bộ (mục 3.4.3), đối chiếu với SRS mục 7.1.

**Bước 7. Checkpoint Sprint 1** (mục 3.5): demo trên Android, sơ đồ chức năng, sơ đồ luồng màn hình, ERD sơ bộ; Sprint Review và Retrospective.

### Vibe coding

```text
Đọc AGENTS.md. Dự án dùng Expo Router (điều hướng theo file).
Tạo các file màn hình còn thiếu theo cây thư mục sau (giữ nguyên các file đã có):
app/_layout.tsx (Stack), app/(tabs)/_layout.tsx (4 tab: index Trang chủ, cart Giỏ hàng,
orders Đơn hàng, account Tài khoản, dùng Ionicons), app/product/[id].tsx, app/category/[id].tsx.
Màn hình chi tiết đọc id bằng useLocalSearchParams, lấy dữ liệu từ data/mock-products.ts.
KHÔNG dùng @react-navigation/stack hoặc NavigationContainer trực tiếp.
```

Kiểm tra kết quả AI:

- AI hay sinh mã React Navigation kiểu cũ (`NavigationContainer`, `createStackNavigator`); dự án dùng Expo Router nên phải loại bỏ.
- `id` từ `useLocalSearchParams` là chuỗi; so sánh với `productId` kiểu số phải chuyển kiểu.
- Nút Back của Android quay về đúng màn hình trước; chuyển tab không mất trạng thái cuộn.
- Hỏi AI: "Vẽ cho tôi sơ đồ luồng màn hình dạng danh sách mũi tên từ cây thư mục app/" để đối chiếu với sơ đồ bạn vẽ, không dùng thay sơ đồ của bạn.
