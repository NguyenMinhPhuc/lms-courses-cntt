## Bài tập hướng dẫn theo dự án LHU Food

**Nhiệm vụ:** khởi tạo hai repo của LHU Food (ứng dụng và API), viết file quy ước cho trợ lý AI từ tài liệu SRS, tạo màn hình đầu tiên bằng vibe coding và hoàn thành quy trình commit, pull request đầu tiên.

- **Tài liệu dùng kèm:** SRS LHU Food, mục 2 (mô tả tổng quan), mục 3 (actor), mục 5.14 (danh sách màn hình).
- **User story:** chuẩn bị cho US-G01, US-G03.
- **Thời lượng gợi ý:** 1,5 tiết trên lớp, hoàn thiện ở nhà.

### Chuẩn bị môi trường

1. Cài Node.js bản LTS, kiểm tra: `node -v`, `npm -v`.
2. Cài Visual Studio Code, Git; đăng nhập GitHub; bật GitHub Copilot Chat (tài khoản sinh viên) hoặc cài Google Antigravity.
3. Trên điện thoại Android: cài Expo Go từ CH Play. Điện thoại và máy tính dùng **cùng một mạng Wi-Fi**. Không có điện thoại: cài Android Studio và tạo một máy ảo (emulator).
4. Kiểm tra Git:

```bash
git config --global user.name "Nguyen Van A"
git config --global user.email "a.nguyen@lhu.edu.vn"
```

### Các bước triển khai

**Bước 1. Tạo dự án ứng dụng.**

```bash
npx create-expo-app@latest lhu-food
cd lhu-food
npx expo start
```

Quét mã QR bằng Expo Go; thấy màn hình mẫu là môi trường đã chạy.

**Bước 2. Đưa lên GitHub.** Trưởng nhóm tạo repo `lhu-food` (và `lhu-food-api`, dùng từ Chương 5), mời thành viên; bật bảo vệ nhánh `main` (bắt buộc pull request, ít nhất 1 người duyệt).

```bash
git init
git add .
git commit -m "chore: khởi tạo dự án Expo"
git branch -M main
git remote add origin https://github.com/<nhom>/lhu-food.git
git push -u origin main
```

**Bước 3. Viết file quy ước cho AI từ SRS.** Tạo `AGENTS.md` ở gốc repo và chép sang `.github/copilot-instructions.md`. Ngoài phần Công nghệ và Quy ước ở mục 1.5.3, bổ sung phần nghiệp vụ tóm tắt từ SRS:

```markdown
## Nghiệp vụ (tóm tắt từ SRS LHU Food)
- Ứng dụng đặt món căn tin. Actor: khách vãng lai, khách hàng (customer), nhân viên (staff).
- Trạng thái đơn: pending → preparing → ready → completed; khách hủy được khi pending.
- Giá và tồn kho luôn do server kiểm tra; giỏ hàng chỉ là ý định mua.
- Thông báo realtime bằng Socket.IO; lưu thông báo vào SQL Server trước khi gửi.

## Cấu trúc màn hình (Expo Router)
- app/(tabs)/index.tsx Trang chủ, cart.tsx Giỏ hàng, orders.tsx Đơn hàng, account.tsx Tài khoản.
- app/product/[id].tsx Chi tiết món, app/category/[id].tsx Món theo danh mục.
```

**Bước 4. Tạo `PROMPTS.md` và `docs/phan-vai.md`.** Bảng phân vai theo mục 1.6: mỗi thành viên phụ trách một nhóm user story trong SRS (ví dụ: A - thực đơn US-G01..G03; B - giỏ hàng, đặt món US-C01..C04; C - xác thực US-G04, G05, C13, C14; D - backend và CSDL).

**Bước 5. Màn hình đầu tiên bằng vibe coding.** Mỗi thành viên tạo nhánh riêng và dùng AI sinh component `ProductCard` (mục 1.7) theo quy trình năm bước ở mục 1.5.2.

### Vibe coding

Mở `AGENTS.md` và file `app/(tabs)/index.tsx` trong cửa sổ chat để AI có ngữ cảnh, rồi gửi prompt:

```text
Đọc AGENTS.md. Tạo component components/ProductCard.tsx cho React Native (TypeScript)
nhận props name: string, price: number, onAdd: () => void.
Hiển thị tên (đậm), giá định dạng tiếng Việt "35.000 đ", nút "Thêm vào giỏ" dùng Pressable,
có hiệu ứng khi nhấn. Chỉ dùng View, Text, Pressable, StyleSheet. Không dùng thẻ HTML,
không thêm thư viện. Sau đó hiển thị 3 thẻ mẫu trong app/(tabs)/index.tsx.
```

Kiểm tra kết quả AI trước khi commit:

- Không có `div`, `span`, `onClick`, `className` (lỗi điển hình ở mục 1.4.2).
- Không có thư viện lạ trong `package.json`.
- Chạy được trên Expo Go, bấm nút có phản hồi.
- Bạn giải thích được từng dòng; dòng nào chưa hiểu thì hỏi lại AI "giải thích dòng này" trước khi giữ.

Ghi vào `PROMPTS.md`: prompt, công cụ, kết quả, những gì bạn sửa.

### Kiểm tra và hoàn thành

- ☐ Repo `lhu-food` có nhánh `main` được bảo vệ, mọi thành viên đã clone và chạy được.
- ☐ `AGENTS.md`, `.github/copilot-instructions.md` có phần nghiệp vụ tóm tắt từ SRS.
- ☐ `docs/phan-vai.md` gán user story SRS cho từng thành viên.
- ☐ Mỗi thành viên có ít nhất một pull request được người khác duyệt và merge.
- ☐ `PROMPTS.md` có ít nhất một mục cho mỗi thành viên.
