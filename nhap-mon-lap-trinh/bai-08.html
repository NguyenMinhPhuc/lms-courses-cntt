BÀI 08 - Hàm cơ bản và tách module (5 tiết: 1,5 LT / 3,5 TH)

Mở lại Student Dashboard v6: đoạn "nhập số an toàn" (vòng while và try – except) có lẽ đã bị chép 3–4 lần. Muốn đổi câu báo lỗi, bạn phải sửa ở 4 chỗ và rất dễ quên một chỗ. Hàm giải quyết đúng vấn đề này.

Mục tiêu: Định nghĩa và gọi được hàm có tham số, giá trị mặc định và return; phân biệt được hàm trả về giá trị với hàm chỉ in; tách được bài toán thành các hàm đơn nhiệm bằng sơ đồ phân rã; tổ chức được chương trình thành nhiều file và dùng import.

Nội dung:

  • Ý chính 1 - Vì sao cần hàm: không lặp code, sửa một nơi, kiểm thử riêng từng phần.

  • Ý chính 3 - print khác return: hàm chỉ in thì không dùng lại được kết quả.
  • Ý chính 4 - Phân rã bài toán và module: sơ đồ phân rã, tách file, import, if __name__ == "__main__":.

📚 2. Học liệu chính ▼

2.1. Vì sao cần hàm

Hàm (function) là một khối lệnh có tên, nhận dữ liệu vào, xử lý và trả kết quả ra. Bạn đã dùng nhiều hàm có sẵn: print(), input(), len(), max(). Bài này bạn tự viết hàm.

  • Không lặp code: viết một lần, gọi nhiều lần. Sửa lỗi ở một chỗ là mọi nơi gọi hàm đều được sửa.
  • Dễ đọc: diem = nhap_so("Điểm: ") nói rõ ý định hơn 8 dòng while – try.
  • Dễ kiểm thử và chia việc: mỗi hàm thử riêng được; trong Mini Project, mỗi thành viên viết một số hàm.

2.2. def, tham số, giá trị mặc định, return

def tinh_diem_tb(qt, gk, ck):
    """Trả về điểm học phần theo trọng số 30-30-40."""
    return qt * 0.3 + gk * 0.3 + ck * 0.4


diem = tinh_diem_tb(8, 7, 9)     # gọi hàm: 8, 7, 9 là đối số
print(f"{diem:.2f}")             # 8.10
  • Tham số (qt, gk, ck) là tên nhận dữ liệu khi định nghĩa; đối số (8, 7, 9) là giá trị truyền vào khi gọi.
  • return kết thúc hàm và trả giá trị về chỗ gọi. Hàm không có return trả về None.
  • Giá trị mặc định: def nhap_so(loi_nhac, nho_nhat=0, lon_nhat=10): cho phép gọi nhap_so("Điểm: ") hoặc nhap_so("Số tín chỉ: ", 1, 5).
  • Trả nhiều giá trị: return min(ds), max(ds), sum(ds) / len(ds); nơi gọi viết thap, cao, tb = thong_ke(ds).

💡 Hàm nhập số an toàn, gom đoạn code đã chép nhiều lần ở bài 06:

def nhap_so(loi_nhac, nho_nhat=0, lon_nhat=10):
    """Hỏi lại tới khi người dùng nhập một số trong [nho_nhat, lon_nhat]."""
    while True:
        try:
            gia_tri = float(input(loi_nhac))
        except ValueError:
            print("Hãy nhập số, dùng dấu chấm cho phần thập phân.")
            continue
        if nho_nhat <= gia_tri <= lon_nhat:
            return gia_tri
        print(f"Giá trị phải trong khoảng {nho_nhat}-{lon_nhat}.")

2.3. print khác return

So sánh hai cách viết hàm xếp loại:

def in_xep_loai(diem):          # chỉ in
    if diem >= 8:
        print("Giỏi")
    else:
        print("Chưa giỏi")


def xep_loai(diem):             # trả về
    if diem >= 8:
        return "Giỏi"
    return "Chưa giỏi"


kq = in_xep_loai(8.5)    # in "Giỏi", nhưng kq là None
kq = xep_loai(8.5)       # kq = "Giỏi": dùng tiếp được
print(f"Bạn đạt loại {kq}")

Quy tắc: hàm tính toán thì return; việc in để cho phần chương trình chính. Hàm return mới ghép được với hàm khác, dùng trong điều kiện if và kiểm thử được bằng cách so kết quả.

2.4. Phân rã bài toán và tách module

Sơ đồ phân rã chức năng: chương trình chính ở trên cùng, mỗi hộp con là một hàm làm một việc: hien_menu(), nhap_so(), tinh_diem_tb(), xep_loai(), thong_ke(). Hộp nào còn làm nhiều việc thì chia tiếp.

Module là một file .py. Đặt các hàm cùng nhóm vào cùng file rồi import:

# main.py  (cùng thư mục với nhap_lieu.py và tinh_toan.py)
from nhap_lieu import nhap_so
from tinh_toan import thong_ke, xep_loai


def main():
    diem_list = []
    while True:
        print("1. Thêm học phần   2. Thống kê   0. Thoát")
        chon = input("Chọn: ").strip()
        if chon == "1":
            diem_list.append(nhap_so("Điểm: "))
        elif chon == "2" and len(diem_list) > 0:
            thap, cao, tb = thong_ke(diem_list)
            print(f"TB: {tb:.2f} ({xep_loai(tb)}) | {thap} - {cao}")
        elif chon == "0":
            break


if __name__ == "__main__":
    main()

if __name__ == "__main__": nghĩa là: chỉ gọi main() khi chạy trực tiếp file này. Khi file khác import nó, các hàm được nạp nhưng menu không tự chạy.

2.5. Nhờ AI đề xuất cách chia hàm

Đây là lúc AI hữu ích: nhìn chương trình dài và gợi ý cách chia. Nhưng hãy giữ phần viết code cho mình.

"Đây là chương trình Python của tôi (dán code). Đề xuất cách chia thành các hàm đơn nhiệm. Với mỗi hàm chỉ nêu: tên, tham số, giá trị trả về, một câu mô tả. Không viết code."

So sánh đề xuất của AI với sơ đồ phân rã của bạn: chọn hàm nào, bỏ hàm nào, vì sao. Ghi quyết định vào Nhật ký Prompt; đây là minh chứng bạn làm chủ thiết kế.
