BÀI 02 - Toán tử, biểu thức và bài toán tính toán (5 tiết: 1,5 LT / 3,5 TH)

Điểm quá trình 8, giữa kỳ 7, cuối kỳ 9. Điểm học phần của bạn là 8,0 hay 8,1? Viết sai một dấu ngoặc trong công thức là chương trình tính sai cho cả lớp mà không báo lỗi gì.

Mục tiêu: Sử dụng được các toán tử số học, so sánh, logic và gán kết hợp; xác định được thứ tự tính của một biểu thức; hiện thực được các bài toán tính toán từ bảng Input – Process – Output.

Nội dung:

  • Ý chính 1 - Toán tử số học: + - * / // % **; khác biệt giữa / và //; dùng % để lấy phần dư.
  • Ý chính 2 - Thứ tự ưu tiên và dấu ngoặc: tính một biểu thức theo từng bước, dùng ngoặc để công thức đúng và dễ đọc.
  • Ý chính 3 - So sánh, logic và gán kết hợp: == != < > <= >=, and or not, +=; biểu thức kiểm tra điểm hợp lệ.
  • Ý chính 4 - Làm tròn, định dạng số và sai số số thực: round(), f-string :.2f, :,; vì sao 0.1 + 0.2 không bằng 0.3.

Kết quả cần đạt: Sinh viên viết được các chương trình đổi đơn vị, tính tiền điện theo bậc và thêm chức năng tính điểm trung bình học phần vào Student Dashboard.

CLO liên quan: CLO1, CLO2.

📚 2. Học liệu chính ▼

2.1. Toán tử số học

Toán tửÝ nghĩaVí dụKết quả
+ - *Cộng, trừ, nhân7 * 321
/Chia, luôn ra số thực7 / 23.5
//Chia lấy phần nguyên7 // 23
%Chia lấy phần dư7 % 21
**Lũy thừa2 ** 101024

💡 Ví dụ: đổi tổng số phút sang giờ và phút. Với 135 phút: 135 // 60 = 2 giờ, 135 % 60 = 15 phút.

tong_phut = int(input("Số phút: "))
gio = tong_phut // 60
phut = tong_phut % 60
print(f"{tong_phut} phút = {gio} giờ {phut} phút")

% còn dùng để tách chữ số: 2007 % 10 cho chữ số hàng đơn vị 7, 2007 // 10 bỏ chữ số đó còn 200.

2.2. Thứ tự ưu tiên và dấu ngoặc

Python tính theo thứ tự (cao đến thấp): ( ) → ** → * / // % → + - → so sánh → not → and → or. Các toán tử cùng mức tính từ trái sang phải (riêng ** tính từ phải sang trái).

💡 Tính từng bước 2 + 3 * 4 ** 2 // 5:

  1. 4 ** 2 = 16 → 2 + 3 * 16 // 5
  2. * và // cùng mức, tính trái sang phải: 3 * 16 = 48, rồi 48 // 5 = 9
  3. 2 + 9 = 11

⚠️ Lỗi hay gặp: 8 + 9 / 2 cho 12.5, không phải trung bình của 8 và 9. Viết đúng là (8 + 9) / 2. Khi không chắc thứ tự, hãy thêm ngoặc: code đúng và người đọc cũng dễ hiểu hơn.

2.3. So sánh, logic và gán kết hợp

  • So sánh cho kết quả True/False: == (bằng, hai dấu bằng), != (khác), < > <= >=. Đừng nhầm == với phép gán =.
  • Logic: a and b đúng khi cả hai đúng; a or b đúng khi ít nhất một đúng; not a đảo giá trị.
  • So sánh nối: Python cho viết 0 <= diem <= 10, tương đương 0 <= diem and diem <= 10.
  • Gán kết hợp: tong += 5 nghĩa là tong = tong + 5; tương tự -=, *=, /=.
diem = 8.5
hop_le = 0 <= diem <= 10           # True
du_hoc_bong = diem >= 8 and hop_le  # True
print(hop_le, du_hoc_bong, not hop_le)   # True True False

2.4. Làm tròn, định dạng số và sai số số thực

  • round(x, 2) làm tròn đến 2 chữ số thập phân; f"{x:.2f}" chỉ định dạng khi in, không đổi giá trị của x.
  • f"{tien:,}" thêm dấu phẩy ngăn cách hàng nghìn: 315000 in thành 315,000.
  • Sai số số thực: máy tính lưu số thực ở hệ nhị phân nên 0.1 + 0.2 cho 0.30000000000000004. Vì vậy không so sánh hai số thực bằng ==; khi in kết quả hãy định dạng với :.2f.

💡 Ví dụ: tiền điện theo bậc. Bảng giá giả định cho bài tập (không phải giá điện thực tế): 50 kWh đầu giá 2.000 đ/kWh, 50 kWh tiếp theo 2.500 đ/kWh, phần còn lại 3.000 đ/kWh. Chưa học if nên ta dùng min(), max() để chia số kWh vào từng bậc.

kwh = int(input("Số kWh tiêu thụ: "))
bac1 = min(kwh, 50)                  # tối đa 50 kWh
bac2 = min(max(kwh - 50, 0), 50)     # phần từ 51 đến 100
bac3 = max(kwh - 100, 0)             # phần trên 100
tien = bac1 * 2000 + bac2 * 2500 + bac3 * 3000
print(f"Tiền điện: {tien:,} đồng")

Với 130 kWh: 50 × 2.000 + 50 × 2.500 + 30 × 3.000 = 315,000 đồng. Hãy tự tính tay trường hợp 40 kWh và 100 kWh để kiểm tra chương trình.

2.5. Student Dashboard v2: điểm trung bình học phần

IPO: Input là điểm quá trình, giữa kỳ, cuối kỳ (thang 10). Process là tb = qt × 0,3 + gk × 0,3 + ck × 0,4 và kiểm tra cả ba điểm nằm trong 0–10. Output là điểm học phần với 2 chữ số thập phân.

qt = float(input("Điểm quá trình: "))
gk = float(input("Điểm giữa kỳ: "))
ck = float(input("Điểm cuối kỳ: "))

tb = qt * 0.3 + gk * 0.3 + ck * 0.4
hop_le = 0 <= qt <= 10 and 0 <= gk <= 10 and 0 <= ck <= 10

print(f"Điểm học phần: {tb:.2f}")
print(f"Dữ liệu hợp lệ: {hop_le}")

Nhập 8, 7, 9 cho 8.10. Lúc này chương trình chỉ báo dữ liệu sai bằng False; bài 03 sẽ dùng if để xử lý từng trường hợp. Prompt gợi ý: "Trình bày từng bước Python tính biểu thức 8 * 0.3 + 7 * 0.3 + 9 * 0.4. Sau đó giải thích vì sao 0.1 + 0.2 lại cho 0.30000000000000004." Chạy thử cả hai biểu thức để kiểm chứng câu trả lời của AI.

🧑‍🏫 Thực hành có hướng dẫn (1,5 tiết): tính tay rồi kiểm tra

  1. Tự tính trên giấy 5 biểu thức giảng viên đưa ra (có //, %, **, ngoặc), sau đó kiểm tra bằng chế độ tương tác.
  2. Hỏi AI trình bày từng bước một biểu thức bạn tính sai; đối chiếu với bảng thứ tự ưu tiên ở mục 2.2.
  3. Viết bảng IPO rồi gõ chương trình đổi phút (mục 2.1) và tiền điện (mục 2.4); chạy thử với 40, 100, 130 kWh.

  1. Student Dashboard v2: thêm phần tính điểm học phần (mục 2.5) vào ho_so.py, in cùng thẻ hồ sơ.

🆘 4. Góc trợ giúp và mở rộng ▼

Nhập 8,5 bị lỗi ValueError: Python dùng dấu chấm cho số thập phân, hãy nhập 8.5. Bài 06 sẽ học cách bắt lỗi này để chương trình không bị dừng.

Kết quả có rất nhiều chữ số lẻ (ví dụ 0.30000000000000004): đây là sai số số thực, không phải lỗi của bạn. In bằng {x:.2f}.

Muốn in tiền theo kiểu Việt Nam (315.000): dùng f"{tien:,}".replace(",", ".").

Kiến thức mở rộng: Tìm hiểu module math (math.sqrt, math.ceil, math.floor) và kiểu decimal.Decimal dùng khi cần tính tiền chính xác tuyệt đối.

Tự đánh giá: Không chạy máy, bạn có tính đúng 17 // 5 * 2 + 17 % 5 ** 2 không? (Đáp án: 23.)
