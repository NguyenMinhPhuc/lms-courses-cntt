BÀI 01 - Làm quen Python và tư duy Input – Process – Output (5 tiết: 1,5 LT / 3,5 TH)

Phòng Đào tạo cần in 3.000 thẻ hồ sơ tân sinh viên, mỗi thẻ gồm họ tên, lớp và tuổi. Làm tay mất cả tuần. Một chương trình 10 dòng làm xong trong vài giây, nhưng chỉ khi người viết biết rõ chương trình nhận vào gì, xử lý gì và in ra gì.

Mục tiêu: Cài đặt được Python 3 và VS Code, chạy được chương trình đầu tiên; phân tích được một bài toán thành Input – Process – Output; khai báo được biến với các kiểu int, float, str, bool và nhập, xuất dữ liệu bằng input(), print(), f-string.

Nội dung:

  • Ý chính 1 - Chương trình và Python: máy tính chỉ làm đúng các lệnh được viết; Python là ngôn ngữ thông dịch, dễ đọc; cài đặt môi trường và chạy print("Hello, LHU!").
  • Ý chính 2 - Tư duy Input – Process – Output (IPO): xác định đầu vào, xử lý, đầu ra trước khi viết code.
  • Ý chính 3 - Biến và kiểu dữ liệu cơ bản: đặt tên biến, bốn kiểu int, float, str, bool, hàm type() và chuyển kiểu.
  • Ý chính 4 - Nhập, xuất và f-string: input() luôn trả về chuỗi; in kết quả gọn gàng bằng f-string; dùng AI giải thích cú pháp và ghi Nhật ký Prompt.

Kết quả cần đạt: Sinh viên chạy được chương trình ho_so.py (phiên bản đầu tiên của Student Dashboard) in thẻ hồ sơ từ dữ liệu nhập vào, kèm bảng IPO và Nhật ký Prompt.

CLO liên quan: CLO1, CLO2.

📚 2. Học liệu chính ▼

2.1. Chương trình, Python và cài đặt môi trường

Chương trình là dãy lệnh viết bằng một ngôn ngữ lập trình để máy tính thực hiện theo đúng thứ tự. Máy tính không đoán ý: viết thiếu một dấu ngoặc là chương trình báo lỗi.

Python là ngôn ngữ thông dịch (interpreted): trình thông dịch đọc file .py và chạy từng lệnh, không cần bước biên dịch riêng. Cú pháp gần với tiếng Anh nên phù hợp người mới học; Python cũng được dùng nhiều trong khoa học dữ liệu, AI và tự động hóa.

Cài đặt (làm trước buổi học):

  1. Tải Python 3.10 trở lên tại python.org/downloads. Trên Windows, ở màn hình đầu tiên của bộ cài, tick ô "Add python.exe to PATH" rồi bấm Install Now.
  2. Cài Visual Studio Code (code.visualstudio.com), mở mục Extensions và cài extension Python của Microsoft.
  3. Mở Terminal trong VS Code (Ctrl + `), gõ python --version (Windows có thể dùng py --version). Thấy Python 3.1x.x là cài đúng.
  4. Tạo file hello.py, gõ dòng dưới đây và bấm nút ▶ (Run Python File).
print("Hello, LHU!")

💡 Hai cách chạy Python: chạy cả file (python hello.py) hoặc gõ python để vào chế độ tương tác (dấu nhắc >>>), gõ lệnh nào chạy ngay lệnh đó. Chế độ tương tác rất tiện để thử nhanh một phép tính; gõ exit() để thoát.

2.2. Tư duy Input – Process – Output

Trước khi mở VS Code, hãy trả lời ba câu hỏi. Đây là thói quen quan trọng nhất của học phần.

  • Input (đầu vào): chương trình cần nhận những dữ liệu nào? Ai cung cấp?
  • Process (xử lý): cần tính toán, so sánh, biến đổi gì từ đầu vào?
  • Output (đầu ra): chương trình in ra gì, theo dạng nào?

💡 Ví dụ: bài toán "in thẻ hồ sơ tân sinh viên".

InputProcessOutput
Họ tên, năm sinh, lớp (người dùng nhập từ bàn phím)Tuổi = năm hiện tại − năm sinhThẻ hồ sơ có khung, gồm họ tên, lớp, tuổi

Viết bảng IPO giúp bạn phát hiện thiếu dữ liệu ngay từ đầu (ví dụ: muốn in tuổi thì phải hỏi năm sinh) và cho AI một mô tả rõ ràng khi cần hỏi.

2.3. Biến và kiểu dữ liệu cơ bản

Biến là một cái tên gắn với một giá trị trong bộ nhớ. Dấu = là phép gán: lấy giá trị bên phải gắn cho tên bên trái.

ho_ten = "Nguyễn Văn An"     # str: chuỗi ký tự, đặt trong ngoặc kép
nam_sinh = 2007              # int: số nguyên
diem_tb = 8.25               # float: số thực, dùng dấu chấm
la_tan_sinh_vien = True      # bool: chỉ có True hoặc False

print(type(nam_sinh))        # <class 'int'>
print(type(diem_tb))         # <class 'float'>
  • Quy tắc đặt tên: chỉ gồm chữ cái, chữ số, dấu gạch dưới; không bắt đầu bằng chữ số; phân biệt hoa thường (diem khác Diem); không trùng từ khóa như if, for.
  • Thói quen tốt: tên có nghĩa, viết thường, nối bằng gạch dưới (nam_sinh, không phải ns hay x1). Đây là kiểu snake_case sẽ học kỹ ở buổi 09.
  • Chuyển kiểu: int("2007") → 2007; float("8.5") → 8.5; str(19) → "19".

⚠️ Chú ý: "2007" (có ngoặc kép) là chuỗi, không phải số. "2007" + 1 gây lỗi TypeError vì Python không cộng chuỗi với số.

2.4. Nhập, xuất và f-string

  • input("Lời nhắc: ") dừng chương trình chờ người dùng gõ và nhấn Enter. Kết quả luôn là chuỗi, muốn tính toán phải chuyển kiểu: int(input(...)).
  • print(a, b) in các giá trị cách nhau một khoảng trắng; sep="-" đổi ký tự ngăn cách, end="" để không xuống dòng.
  • f-string: đặt chữ f trước chuỗi, giá trị biến nằm trong { }: f"{ho_ten} - {tuoi} tuổi".

💡 Ví dụ: thẻ hồ sơ số hóa cá nhân, phiên bản 1 của Student Dashboard.

# ho_so.py - Student Dashboard v1: in thẻ hồ sơ
ho_ten = input("Họ tên: ")
nam_sinh = int(input("Năm sinh: "))
lop = input("Lớp: ")

tuoi = 2026 - nam_sinh

print("=" * 36)
print(f"  HỒ SƠ SỐ HÓA: {ho_ten}")
print(f"  Lớp: {lop}  |  Tuổi: {tuoi}")
print("=" * 36)

Nhập Nguyễn Văn An, 2007, 26CT111 sẽ in ra khung có dòng Lớp: 26CT111 | Tuổi: 19. Biểu thức "=" * 36 lặp chuỗi "=" 36 lần để vẽ khung.

2.5. Dùng AI đúng cách và Nhật ký Prompt

Trong học phần này, AI là trợ giảng: giải thích, gợi ý, tìm lỗi. Bạn là người viết code. Một prompt tốt cho người mới học có ba phần: bối cảnh, câu hỏi cụ thể, giới hạn.

💡 Prompt mẫu:

"Tôi là sinh viên năm nhất mới học Python buổi đầu. Giải thích dòng print(f"Tuổi: {tuoi}") làm gì, chữ f và dấu ngoặc nhọn có ý nghĩa gì. Đừng viết thêm code mới, chỉ giải thích."

Nhật ký Prompt (file nhat-ky-prompt.md, ghi cho mọi bài lab) gồm các cột:

Prompt mẫu ở trênf-string chèn giá trị biến vào chuỗiTự viết lại dòng in lớp và tuổi, chạy thử đúngThiếu chữ f thì in nguyên chữ {tuoi}

🆘 4. Góc trợ giúp và mở rộng ▼

Gõ python mà báo "not recognized" hoặc mở Microsoft Store: lúc cài chưa tick "Add python.exe to PATH". Thử lệnh py, hoặc chạy lại bộ cài, chọn Modify và bật tùy chọn thêm vào PATH. Trong Windows Settings, mục App execution aliases, tắt hai mục python.exe của App Installer.

Nút ▶ không chạy hoặc báo thiếu trình thông dịch: nhấn Ctrl + Shift + P, chọn Python: Select Interpreter và chọn bản Python vừa cài.

SyntaxError: unterminated string literal: thiếu dấu ngoặc kép đóng chuỗi. TypeError: can only concatenate str (not "int") to str: đang cộng chuỗi với số, kiểm tra đã dùng int() sau input() chưa.

Kiến thức mở rộng: Thử hàm help(print) trong chế độ tương tác để đọc tài liệu của một hàm; tìm hiểu cách định dạng số trong f-string như {chieu_cao:.2f} (sẽ dùng ở bài 02).
