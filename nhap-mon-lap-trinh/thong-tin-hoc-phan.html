2.3. Công cụ sử dụng

  • Ngôn ngữ: Python 3.10 trở lên.
  • Trình soạn thảo: Visual Studio Code với extension Python (Microsoft) và Ruff (kiểm tra chuẩn PEP 8).
  • Trợ lý AI: một trong ChatGPT, Claude, Gemini (bản miễn phí là đủ).
  • Vẽ lưu đồ: Draw.io (diagrams.net), dùng bản web hoặc extension trong VS Code.
  • Quản lý mã nguồn: GitHub (giao diện web hoặc GitHub Desktop), dùng từ buổi 11.

💡 3. Cách học & quy tắc dùng AI ▼

🔄 Lớp học đảo ngược

Trước mỗi buổi, đọc phần Học liệu chính của bài trên LMS và làm quiz luyện tập. Thời gian trên lớp dành cho lab: bạn code, giảng viên đi từng máy hỗ trợ.

🧠 Nghĩ trước, code sau

Với mọi bài, viết bảng Input – Process – Output trước; từ buổi 03 vẽ thêm lưu đồ. Chỉ mở VS Code khi đã biết chương trình cần làm gì.

🤖 AI là trợ giảng, không phải người làm hộ

  • Nên hỏi AI: giải thích cú pháp, giải thích thông báo lỗi, chỉ ra dòng sai, gợi ý hướng giải, cho ví dụ tương tự ở mức nhập môn.
  • Không nên: dán nguyên đề và nộp nguyên đoạn code AI viết. Code nộp phải do bạn gõ và giải thích được từng dòng.
  • Nhật ký Prompt: mỗi bài lab ghi lại prompt đã dùng, AI trả lời gì, bạn đã kiểm tra và sửa ra sao. Nhật ký là một phần điểm quá trình.
  • Kiểm chứng: AI có thể sai. Luôn chạy thử với nhiều bộ dữ liệu, kể cả dữ liệu sai và giá trị biên.

📝 Chuẩn bị trước buổi 01

Laptop cài sẵn Python 3.10+ và VS Code (xem hướng dẫn trong Bài 01); một tài khoản AI (ChatGPT, Claude hoặc Gemini); tạo thư mục nhap-mon-lap-trinh để lưu bài lab cả học kỳ.
