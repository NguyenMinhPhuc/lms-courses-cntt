Trong Git, commit là gì?
A. Lệnh xóa repository
B. Một lần lưu thay đổi của mã nguồn kèm thông điệp mô tả
C. Một file cấu hình của GitHub
D. Lệnh chạy chương trình Python
ANSWER: B

Thao tác push có tác dụng gì?
A. Lấy thay đổi mới của bạn cùng nhóm về máy
B. Tạo repository mới
C. Đẩy các commit trên máy lên repository trên GitHub
D. Xóa commit cuối cùng
ANSWER: C

Thao tác pull dùng để làm gì?
A. Lấy các thay đổi mới trên GitHub về máy mình
B. Mời thành viên vào repository
C. Đẩy code lên GitHub
D. Đổi tên repository
ANSWER: A

Thông điệp commit nào tốt nhất?
A. update
B. final
C. sửa
D. Sửa lỗi chia cho 0 khi chưa có khoản chi
ANSWER: D

GitHub Desktop báo push bị từ chối (rejected) vì trên GitHub đã có commit mới của bạn khác. Nên làm gì?
A. Đổi tên file rồi push
B. Xóa repository và tạo lại
C. Pull về trước rồi push lại
D. Gửi code qua tin nhắn thay vì push
ANSWER: C

Xung đột (conflict) khi ghép code thường xảy ra khi nào?
A. Hai người commit vào hai file khác nhau
B. Hai người sửa cùng một đoạn trong cùng một file
C. Một người viết README
D. Repository có nhiều hơn 3 file
ANSWER: B

A. Thử từng hàm riêng lẻ trong chế độ tương tác
B. Đọc lại code bằng mắt

Với chức năng "Thêm khoản chi" có ngân sách còn lại 200.000 đồng, dữ liệu nào là giá trị biên?

Trên GitHub, minh chứng nào thể hiện vai trò cá nhân (CLO3) rõ nhất?

A. Chuẩn bị sẵn dữ liệu, chạy chức năng chính và cố ý nhập sai một lần để cho thấy chương trình không dừng
