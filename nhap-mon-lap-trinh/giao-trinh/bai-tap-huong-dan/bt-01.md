## Bài tập hướng dẫn: Student Dashboard v1

**Nhiệm vụ:** viết chương trình `ho_so.py` in thẻ hồ sơ cá nhân từ dữ liệu người dùng nhập, là phiên bản đầu tiên của Student Dashboard.

- **Thời lượng gợi ý:** 2 tiết thực hành tự làm.
- **Sản phẩm:** `ho_so.py`, bảng IPO, `nhat-ky-prompt.md` có 2–3 prompt.

### Chuẩn bị

1. Kiểm tra `python --version` và extension Python trong VS Code (mục 1.2.1).
2. Tạo thư mục `nhap-mon-lap-trinh/buoi-01`, mở bằng VS Code, tạo file `ho_so.py` và `nhat-ky-prompt.md`.

### Các bước thực hiện

**Bước 1. Lập bảng IPO.** Thẻ hồ sơ cần thêm các thông tin so với Ví dụ 1.5: mã số sinh viên, quê quán, chiều cao (mét) và có ở ký túc xá hay không.

| Thành phần | Nội dung |
|---|---|
| Input | Họ tên, mã số sinh viên, năm sinh, lớp, quê quán, chiều cao, trả lời có ở ký túc xá (c/k) |
| Process | Tuổi = 2026 − năm sinh; `o_ktx = tra_loi == "c"` |
| Output | Thẻ hồ sơ có khung, mỗi thông tin một dòng |

**Bước 2. Nhập dữ liệu với đúng kiểu.** Năm sinh là `int`, chiều cao là `float`, các thông tin còn lại là `str`.

```python
ho_ten = input("Họ tên: ")
mssv = input("Mã số sinh viên: ")
nam_sinh = int(input("Năm sinh: "))
lop = input("Lớp: ")
que_quan = input("Quê quán: ")
chieu_cao = float(input("Chiều cao (m): "))
tra_loi = input("Ở ký túc xá? (c/k): ")
```

Mã số sinh viên giữ kiểu chuỗi dù chỉ gồm chữ số: không ai cộng trừ mã số sinh viên, và mã có thể bắt đầu bằng số 0.

**Bước 3. Xử lý.** Biểu thức so sánh `tra_loi == "c"` cho ra `True` hoặc `False`, lưu vào một biến kiểu `bool`.

```python
tuoi = 2026 - nam_sinh
o_ktx = tra_loi == "c"
```

**Bước 4. In thẻ hồ sơ.** Dùng f-string, mỗi thông tin một dòng, khung bằng `"=" * 36`. Thử in chiều cao bằng `{chieu_cao}` và quan sát kết quả.

**Bước 5. Hỏi AI để hiểu, không để làm hộ.** Ví dụ prompt: *"Tôi mới học Python buổi đầu. Vì sao `o_ktx = tra_loi == "c"` lại cho ra True hoặc False? Chỉ giải thích, đừng viết code mới."* Ghi vào Nhật ký Prompt theo Bảng 1.7.

### Kiểm tra kết quả

| Dữ liệu thử | Kết quả mong đợi |
|---|---|
| Năm sinh `2007`, ký túc xá `c` | Tuổi 19, ký túc xá `True` |
| Năm sinh `2006`, ký túc xá `k` | Tuổi 20, ký túc xá `False` |
| Ký túc xá nhập `C` (chữ hoa) | Ký túc xá `False`; ghi lại vì sao, Chương 3 sẽ xử lý trường hợp này |

### Tiêu chí hoàn thành

- Chương trình chạy đúng với ít nhất hai bộ dữ liệu khác nhau.
- Bảng IPO khớp với mã nguồn: mọi dòng Output đều được in.
- Giải thích được vì sao phải dùng `int()` cho năm sinh và `float()` cho chiều cao.
- Nhật ký Prompt có ít nhất hai dòng, mỗi dòng có phần "mình kiểm tra hoặc sửa gì".
