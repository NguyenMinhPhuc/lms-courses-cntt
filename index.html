CƠ CHẾ TỰ ĐỘNG NHẬN DIỆN

Bạn vừa thêm một thư mục học phần mới?

Chỉ cần tạo thư mục mới (ví dụ lap-trinh-web) và đặt file index.html bên trong. Khi mở qua Local Server (đã có sẵn file start-portal.bat), trang web sẽ tự động duyệt cây thư mục và hiển thị học phần mới lên đây ngay lập tức!

Hướng Dẫn Thêm Học Phần Mới

Hệ thống sẽ tự động hiển thị học phần mới mà không cần code lại trang chủ

1 Tạo thư mục học phần:

Tạo một thư mục mới trong thư mục gốc của dự án, ví dụ:

lms-courses-cntt/
├── nhap-mon-nganh/       # Học phần hiện tại
├── lap-trinh-web/        # Thư mục học phần mới
│   ├── index.html        # Trang mặc định bắt buộc
│   ├── thong-tin-hoc-phan.html (tùy chọn)
│   └── danh-gia-hoc-phan.html (tùy chọn)
└── index.html            # Trang tổng hợp này
2 Tạo file index.html bên trong thư mục:

Trang tổng hợp sẽ tự động đọc thẻ <title>, <meta name="description"> và mã học phần từ file index.html để hiển thị tên, mô tả và icon tương ứng.

3 Cách chạy để trang tự động nhận diện 100%:

Cách 1 (Khuyên dùng): Click đúp vào file start-portal.bat trong thư mục gốc. Trình duyệt sẽ mở http://localhost:8000. Tại đây, mọi thư mục mới thêm vào sẽ tự động hiện lên khi tải lại trang!

Cách 2: Nhấp nút "Chọn thư mục để quét" ngay trên trang này, chọn thư mục dự án lms-courses-cntt để cấp quyền cho trình duyệt tự động quét các thư mục con.

Cách 3: Chạy lệnh uv run python scan-courses.py bất cứ lúc nào để cập nhật danh mục vào courses.json.
