## Mô tả
Môn học cung cấp cho sinh viên kiến thức và kỹ năng xây dựng các dịch vụ Web API sử dụng ASP.NET Core 8, kết hợp Dapper ORM và stored procedure. Sinh viên sẽ được thực hành thiết kế, triển khai, truy vấn dữ liệu và xây dựng API theo chuẩn RESTful phục vụ cho hệ thống phần mềm hiện đại.
Các khái niệm tổng quan về RESTful WebService, IIS WebServer.
Cách thức tổ chức dự án website theo mô hình Backend và Front-end.
Kết nối website với cơ sở dữ liệu MS SQL server sử dụng Dapper ORM
Tương tác với RESTfull WebService.
Các kiến thức để xây dựng RESTful WebService hoàn chỉnh.
