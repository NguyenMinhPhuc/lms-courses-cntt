## Mô tả
Môn học cung cấp kiến thức và kỹ năng xây dựng ứng dụng web hiện đại sử dụng React JS cho frontend và ASP.NET Core Web API 8.0 cho backend. Sinh viên sẽ học cách thiết kế giao diện, kết nối API, xử lý dữ liệu và triển khai ứng dụng thực tế.

| CLO | Nội dung chuẩn đầu ra học phần | Cấp độ (Bloom domain/level) | PLO/SO/PI |
|---|---|---|---|
| CLO1 | Trình bày được kiến thức cơ bản về mô hình Client-Server và nguyên lý hoạt động của Web API |  | PI1.1 |
| CLO2 | Áp dụng ReactJS để xây dựng giao diện người dùng |  | PI2.1 |
| CLO3 | Xây dựng API RESTful với ASP.NET Core 8.0 |  | PI2.2 |
| CLO4 | Thực hiện kết nối frontend và backend, xử lý truy vấn, pagination, tìm kiếm và phân quyền |  | PI3.1 |
| CLO5 | Triển khai ứng dụng web lên môi trường server thực tế |  | PI3.2 |
