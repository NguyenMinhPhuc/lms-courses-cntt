BÀI 08 - Trang quản trị: CRUD, tải ảnh, báo cáo & biểu đồ (5 tiết: 1 LT / 4 TH)

Cuối tuần, quản lý căn tin muốn biết: tuần này bán được bao nhiêu, món nào bán chạy, bao nhiêu đơn bị hủy. Họ không mở SSMS, cũng không đọc JSON. Họ cần một trang quản trị: thêm món mới kèm ảnh trong một phút, nhìn biểu đồ là hiểu, bấm một nút là có file Excel gửi cho kế toán.

Mục tiêu: Xây dựng được trang quản trị CRUD theo một mẫu thống nhất; tải được ảnh lên API có kiểm tra định dạng và dung lượng; trình bày được số liệu báo cáo bằng biểu đồ và xuất được file CSV; kiểm thử được các ràng buộc nghiệp vụ quản trị.

Nội dung:

  • Ý chính 1 - Mẫu trang CRUD: danh sách, tạo, sửa, ngừng bán; một form dùng chung cho tạo và sửa; hộp thoại xác nhận.
  • Ý chính 2 - Tải ảnh món: FormData qua Server Action tới API, xem trước, giới hạn định dạng và dung lượng.
  • Ý chính 3 - Báo cáo và biểu đồ: doanh thu, món bán chạy, tỉ lệ trạng thái bằng Recharts; chọn khoảng ngày; xuất CSV.
  • Ý chính 4 - Tài khoản nhân viên và test case quản trị: tạo, khóa, mở khóa (US-A04); kiểm thử các ràng buộc.

Kết quả cần đạt: Trang quản lý món (US-A02) có ảnh, trang báo cáo (US-A05, A06) có biểu đồ và nút xuất CSV, trang tài khoản nhân viên (US-A04), chạy trên backend nhóm; bộ test case quản trị kèm kết quả.

CLO liên quan: CLO1, CLO2.

📚 2. Học liệu chính ▼

2.1. Mẫu trang CRUD

Mọi trang quản trị (món, danh mục, quầy, tài khoản) dùng cùng một cấu trúc. Người dùng học một lần là dùng được mọi trang, nhóm viết một lần là nhân bản được:

app/admin/products/
  page.tsx             danh sách (Server Component, bảng bài 06)
  new/page.tsx         tạo mới  → <ProductForm />
  [id]/edit/page.tsx   sửa      → <ProductForm product={product} />
  product-form.tsx     form dùng chung (Client Component)
  actions.ts           saveProduct, uploadProductImage, toggleAvailability
// app/admin/products/actions.ts
'use server';
import { redirect } from 'next/navigation';
import { revalidatePath } from 'next/cache';
import { productSchema } from '@/lib/schemas';
import { requireRole } from '@/lib/dal';
import { apiAuth, ApiError } from '@/lib/api';

export type FormState = { ok: boolean; message?: string; fieldErrors?: Record<string, string[]> };

// id có giá trị: sửa; không có: tạo mới. Gắn id bằng saveProduct.bind(null, product?.id)
export async function saveProduct(id: number | undefined, _prev: FormState, formData: FormData): Promise<FormState> {
  await requireRole('admin');
  const parsed = productSchema.safeParse(Object.fromEntries(formData));   // price, categoryId: z.coerce.number()
  if (!parsed.success) return { ok: false, fieldErrors: parsed.error.flatten().fieldErrors };
  try {
    await apiAuth(id ? `/admin/products/${id}` : '/admin/products', {
      method: id ? 'PUT' : 'POST', body: JSON.stringify(parsed.data),
    });
  } catch (e) {
    if (e instanceof ApiError && e.status === 404) return { ok: false, message: 'Danh mục hoặc món không còn tồn tại' };
    return { ok: false, message: 'Chưa lưu được món, vui lòng thử lại' };
  }
  revalidatePath('/admin/products');
  revalidatePath('/menu');                           // thực đơn của khách cũng đổi
  redirect('/admin/products');
}
  • Form dùng useActionState(saveProduct.bind(null, product?.id), { ok: false }); defaultValue lấy từ product khi sửa. Lỗi từng trường lấy từ state.fieldErrors.
  • Không có nút "Xóa món". Món đã có trong đơn chỉ được ngừng bán (BR-16), dùng nút bật/tắt của bài 06. Thao tác không hoàn tác được (xóa danh mục, khóa tài khoản) phải qua AlertDialog của shadcn/ui ghi rõ hậu quả.
  • Sau khi lưu, thông báo ngắn (toast) "Đã lưu món Cơm gà xối mỡ" và quay về danh sách.

2.2. Tải ảnh món

Trình duyệt gửi file tới Server Action, Server Action kiểm tra rồi chuyển tiếp tới API kèm token. API (Multer, trường file) lưu ảnh và stored procedure cập nhật ImageUrl.

// app/admin/products/actions.ts (tiếp; thêm import { getAccessToken } from '@/lib/session')
const IMAGE_TYPES = ['image/jpeg', 'image/png', 'image/webp'];
const MAX_BYTES = 2 * 1024 * 1024;

export async function uploadProductImage(productId: number, _prev: FormState, formData: FormData): Promise<FormState> {
  await requireRole('admin');
  const file = formData.get('file');
  if (!(file instanceof File) || file.size === 0) return { ok: false, message: 'Chọn một ảnh' };
  if (!IMAGE_TYPES.includes(file.type)) return { ok: false, message: 'Chỉ nhận ảnh JPG, PNG hoặc WEBP' };
  if (file.size > MAX_BYTES) return { ok: false, message: 'Ảnh tối đa 2 MB' };

  const body = new FormData();
  body.append('file', file);
  const res = await fetch(`${process.env.API_URL}/admin/products/${productId}/image`, {
    method: 'POST',
    headers: { Authorization: `Bearer ${await getAccessToken()}` },   // KHÔNG tự đặt Content-Type
    body,
  });
  if (!res.ok) return { ok: false, message: res.status === 413 ? 'Ảnh vượt quá dung lượng cho phép' : 'Tải ảnh thất bại' };
  revalidatePath('/admin/products');
  return { ok: true, message: 'Đã cập nhật ảnh' };
}
// next.config.ts
const nextConfig = {
  experimental: { serverActions: { bodySizeLimit: '3mb' } },     // mặc định 1 MB
  images: { remotePatterns: [new URL(`${process.env.API_URL}/uploads/**`)] },  // cho phép next/image
};
export default nextConfig;
  • Không tự đặt Content-Type khi gửi FormData: fetch tự sinh multipart/form-data; boundary=…. Vì vậy upload không dùng apiAuth (hàm đó luôn đặt JSON), giống lưu ý ở Chương 8 giáo trình di động.
  • Xem trước ở client: <input type="file" accept="image/jpeg,image/png,image/webp">, khi chọn file thì URL.createObjectURL(file) rồi hiện bằng <img>; gọi URL.revokeObjectURL khi đổi file.
  • Kiểm tra định dạng ở ba nơi: thuộc tính accept (tiện cho người dùng), Server Action (chặn sớm), API (chặn thật). Không tin phần mở rộng tên file.

2.3. Báo cáo và biểu đồ

Trang /admin/reports?from=2026-10-01&to=2026-10-31: Server Component đọc khoảng ngày từ URL, gọi ba API báo cáo cùng lúc, truyền dữ liệu cho biểu đồ (Client Component). Recharts vẽ bằng JavaScript nên bắt buộc chạy ở client.

// app/admin/reports/page.tsx
export default async function ReportsPage({ searchParams }: { searchParams: Promise<{ from?: string; to?: string }> }) {
  await requireRole('admin');
  const { from = firstDayOfMonth(), to = today() } = await searchParams;
  if (from > to) return <p role="alert">Ngày bắt đầu phải trước hoặc bằng ngày kết thúc.</p>;
  const q = `from=${from}&to=${to}`;
  const [revenue, top, status] = await Promise.all([
    apiAuth<{ day: string; orderCount: number; revenue: number }[]>(`/reports/revenue?${q}`),
    apiAuth<{ id: number; name: string; quantity: number; revenue: number }[]>(`/reports/top-products?${q}&top=5`),
    apiAuth<{ status: string; orderCount: number; percentage: number }[]>(`/reports/order-status?${q}`),
  ]);
  return <ReportView revenue={revenue} top={top} status={status} from={from} to={to} />;
}
// app/admin/reports/revenue-chart.tsx   (npm install recharts)
'use client';
import { Bar, BarChart, CartesianGrid, ResponsiveContainer, Tooltip, XAxis, YAxis } from 'recharts';

const vnd = (n: number) => `${n.toLocaleString('vi-VN')} đ`;

export function RevenueChart({ data }: { data: { day: string; revenue: number }[] }) {
  return (
    <figure>
      <figcaption className="font-bold">Doanh thu theo ngày (không tính đơn đã hủy)</figcaption>
      <ResponsiveContainer width="100%" height={280}>
        <BarChart data={data}>
          <CartesianGrid vertical={false} strokeDasharray="3 3" />
          <XAxis dataKey="day" tickFormatter={(d: string) => d.slice(8, 10) + '/' + d.slice(5, 7)} />
          <YAxis tickFormatter={(n: number) => `${n / 1000}k`} />
          <Tooltip formatter={(n: number) => vnd(n)} labelFormatter={(d: string) => `Ngày ${d}`} />
          <Bar dataKey="revenue" name="Doanh thu" fill="#1e3a8a" radius={[4, 4, 0, 0]} />
        </BarChart>
      </ResponsiveContainer>
    </figure>
  );
}
  • Chọn biểu đồ theo câu hỏi: doanh thu theo thời gian dùng cột hoặc đường; món bán chạy dùng cột ngang, sắp xếp giảm dần; tỉ lệ trạng thái (US-A06) dùng cột chồng 100% hoặc bảng có phần trăm. Biểu đồ tròn chỉ hợp khi có ít nhóm.
  • Một màu cho một chuỗi số liệu; không dùng màu để phân biệt các ngày. Luôn có tiêu đề, đơn vị và bảng số liệu bên dưới cho người không xem được biểu đồ.
  • Số liệu phải khớp với truy vấn trực tiếp trên CSDL (tiêu chí US-A05). Đây là một test case bắt buộc.

Xuất CSV cho Excel bằng Route Handler, vì cần trả về file chứ không phải trang:

// app/admin/reports/export/route.ts   → <a href={`/admin/reports/export?from=${from}&to=${to}`}>
export async function GET(req: Request) {
  await requireRole('admin');
  const { searchParams } = new URL(req.url);
  const q = `from=${searchParams.get('from')}&to=${searchParams.get('to')}`;
  const rows = await apiAuth<{ day: string; orderCount: number; revenue: number }[]>(`/reports/revenue?${q}`);
  const csv = ['Ngày,Số đơn,Doanh thu', ...rows.map((r) => `${r.day},${r.orderCount},${r.revenue}`)].join('\r\n');
  return new Response('﻿' + csv, {                     // BOM: Excel đọc đúng tiếng Việt
    headers: {
      'Content-Type': 'text/csv; charset=utf-8',
      'Content-Disposition': `attachment; filename="doanh-thu-${searchParams.get('from')}.csv"`,
    },
  });
}

Thư mục /admin đã được proxy.ts bảo vệ, nhưng Route Handler vẫn gọi requireRole (nguyên tắc ba lớp của bài 05). Nếu nội dung có dấu phẩy (tên món), bọc giá trị trong dấu nháy kép.

🧑‍🏫 Thực hành có hướng dẫn (2 tiết): Quản lý món và báo cáo doanh thu

  1. Thêm productSchema vào lib/schemas.ts; tạo product-form.tsx, trang new và [id]/edit dùng chung form.
  2. Khối tải ảnh trên trang sửa món: chọn file, xem trước, gửi qua uploadProductImage; cấu hình next.config.ts.
  3. Trang /admin/reports: bộ chọn khoảng ngày (form GET), biểu đồ doanh thu, bảng 5 món bán chạy, bảng tỉ lệ trạng thái.
  4. Route Handler xuất CSV; mở bằng Excel.
  5. Chạy TC-41…TC-46, TC-49; ghi kết quả.

🆘 4. Góc trợ giúp và mở rộng ▼

Lỗi "Body exceeded 1 MB limit" khi tải ảnh: chưa tăng serverActions.bodySizeLimit trong next.config.ts, hoặc chưa khởi động lại npm run dev sau khi sửa.

API báo "Không có file" dù đã chọn ảnh: đã tự đặt Content-Type, hoặc tên trường không phải file, hoặc thiếu thuộc tính name="file" trên ô chọn file.

next/image báo "hostname is not configured": thêm địa chỉ API vào images.remotePatterns. Khi imageUrl rỗng, hiện ảnh thay thế.

Biểu đồ trống hoặc báo lỗi "window is not defined": component Recharts thiếu 'use client'; hoặc ResponsiveContainer nằm trong khối không có chiều cao.

Kiến thức mở rộng: xuất file .xlsx có định dạng bằng thư viện ExcelJS trong Route Handler; nén ảnh trước khi tải lên bằng canvas ở client để giảm dung lượng.
