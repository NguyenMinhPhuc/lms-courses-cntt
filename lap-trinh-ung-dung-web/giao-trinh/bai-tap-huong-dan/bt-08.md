## Bài tập hướng dẫn theo dự án LHU Food

**Nhiệm vụ:** hoàn thiện trang quản lý món (CRUD và ảnh), trang báo cáo có biểu đồ và xuất CSV, trang tài khoản nhân viên; kiểm thử các ràng buộc quản trị.

- **Tài liệu dùng kèm:** SRS mục 4.7 (tiêu chí US-A01, A02, A04, A05), 5.11 (F10.1–F10.3), 5.12 (F11.2, F11.4), 6 (BR-16), 8 (`/admin/products`, `/admin/users`, `/reports/*`).
- **User story:** US-A02, US-A04, US-A05, US-A06.
- **Thời lượng gợi ý:** 2 tiết trên lớp.

### Chuẩn bị môi trường

```bash
git checkout main && git pull
git checkout -b feature/admin-pages
npm install recharts
npx shadcn@latest add select textarea alert-dialog sonner
```

Backend nhóm đã có API quản trị món, tài khoản và báo cáo (Chương 7 và Chương 7 giáo trình di động). Chuẩn bị một ảnh JPG dưới 2 MB, một ảnh 2,5 MB và một file PDF đổi tên thành `.jpg` để thử.

### Các bước triển khai

**Bước 1. Schema và form.** Thêm `productSchema` vào `lib/schemas.ts` (giá > 0, tên 2–150 ký tự, `z.coerce.number()` cho giá và danh mục); `product-form.tsx` dùng chung cho `new` và `[id]/edit`.

**Bước 2. Server Actions.** `saveProduct`, `uploadProductImage` (mục 8.1.2, 8.2.2); cấu hình `next.config.ts` (mục 8.2.3).

**Bước 3. Tải ảnh.** Trên trang sửa món: chọn file, xem trước, gửi; ảnh mới hiện ở danh sách và thực đơn.

**Bước 4. Báo cáo.** `/admin/reports` với bộ chọn khoảng ngày, biểu đồ doanh thu, bảng 5 món bán chạy, bảng tỉ lệ trạng thái.

**Bước 5. Xuất CSV.** Route Handler `/admin/reports/export` (mục 8.4); mở file bằng Excel.

**Bước 6. Tài khoản nhân viên.** Trang `/admin/users` (mục 8.5.1).

**Bước 7. Kiểm thử.** Chạy TC-41…TC-49, ghi kết quả vào `docs/test/sprint-3-quan-tri.md`; TC-45 có ảnh chụp truy vấn SSMS làm minh chứng.

### Vibe coding

```text
Đọc AGENTS.md, app/admin/products/actions.ts. Tạo app/admin/reports/revenue-chart.tsx là Client Component
dùng recharts: BarChart một màu (#1e3a8a), trục X là ngày dạng dd/mm, trục Y rút gọn "k",
Tooltip định dạng "35.000 đ"; bọc trong <figure> có <figcaption> "Doanh thu theo ngày (không tính đơn đã hủy)".
Bên dưới biểu đồ có <table> liệt kê đủ số liệu. KHÔNG gọi API trong component này (nhận data qua props),
KHÔNG dùng nhiều màu cho một chuỗi số liệu.
```

Kiểm tra kết quả AI:

- Biểu đồ nhận dữ liệu qua props, không tự `fetch`; trang báo cáo vẫn là Server Component.
- Upload không đặt `Content-Type` thủ công; AI rất hay thêm `'Content-Type': 'multipart/form-data'`.
- `redirect` không nằm trong `try`.
- So số liệu biểu đồ với SSMS (TC-45) trước khi tin.

### Kiểm tra và hoàn thành

- ☐ Thêm, sửa món, tải ảnh hoạt động; không có nút xóa món; ngừng bán thay cho xóa.
- ☐ Báo cáo có biểu đồ, bảng số liệu, khoảng ngày trên URL; CSV mở đúng tiếng Việt.
- ☐ Trang tài khoản tạo, khóa, mở khóa được; tự khóa bị chặn.
- ☐ `docs/test/sprint-3-quan-tri.md` có kết quả TC-41…TC-49 kèm minh chứng.
