## Bài tập hướng dẫn theo dự án LHU Food

**Nhiệm vụ:** dựng khung route và layout cho khu vực khách và khu vực quản trị theo bảng ánh xạ; giao diện responsive với Tailwind CSS và shadcn/ui; lập sơ đồ chức năng và sitemap của nhóm.

- **Tài liệu dùng kèm:** SRS mục 5.1 (module), 5.14.2 (màn hình web), 8 (danh mục API).
- **User story:** US-G01, US-G03 (khung trang); khung cho US-S02, US-A02.
- **Thời lượng gợi ý:** 2 tiết trên lớp.

### Chuẩn bị môi trường

```bash
git checkout main && git pull
git checkout -b feature/routing-layout
npx shadcn@latest init
npx shadcn@latest add button card table dialog sheet
```

Tạo `lib/mock.ts` chứa 8–10 món giả có cùng tên trường với API mẫu (ghi trong `docs/api-notes.md` ở bài 01) để sau này thay bằng dữ liệu thật mà không sửa giao diện.

### Các bước triển khai

**Bước 1. Bảng ánh xạ.** Hoàn thành bảng route – chức năng – vai trò – API (mục 2.1.2) cho phạm vi web của nhóm, lưu `docs/anh-xa-route.md`.

**Bước 2. Cây thư mục.** Chuyển trang `/menu` vào route group `(shop)`, tạo `(shop)/layout.tsx` có header (logo, liên kết Thực đơn, Giỏ hàng). Tạo `admin/layout.tsx` theo mục 2.3.1 và các trang `admin/orders`, `admin/products` chỉ có tiêu đề.

**Bước 3. Lưới món.** Trang `/menu` hiển thị món giả bằng `Card` của shadcn/ui, lưới 1/2/3 cột (mục 2.4.2), giá dạng "35.000 đ".

**Bước 4. Route động.** `/product/[id]` đọc `params` (mục 2.2.3), hiện tên, mô tả, giá; `id` sai gọi `notFound()`; tạo `app/not-found.tsx` thân thiện có liên kết về thực đơn.

**Bước 5. Sơ đồ.** Vẽ sơ đồ chức năng và sitemap bằng draw.io, lưu file nguồn và ảnh trong `docs/`.

### Vibe coding

```text
Đọc AGENTS.md và docs/anh-xa-route.md. Dự án Next.js App Router, Tailwind CSS, shadcn/ui.
Tạo app/(shop)/layout.tsx có header gồm logo "LHU Food", liên kết /menu và /cart (dùng next/link),
và app/(shop)/product/[id]/page.tsx là Server Component async:
params có kiểu Promise<{ id: string }>, await params, tìm món trong lib/mock.ts bằng Number(id),
không thấy thì gọi notFound(). Dùng Card của components/ui. Không dùng "use client".
```

Kiểm tra kết quả AI:

- `params` được khai báo là `Promise` và được `await` (mã cũ hay viết `params.id` trực tiếp).
- Không có `useRouter` hay `useState` trong trang chi tiết.
- Không có thư mục `pages/`; không có thư viện UI mới trong `package.json`.
- Class Tailwind viết đủ tên, không ghép chuỗi động.
