## Bài tập hướng dẫn theo dự án LHU Food

**Nhiệm vụ:** triển khai web và backend nhóm lên Windows Server của Khoa, qua đủ danh sách kiểm tra, viết README triển khai; hoàn thành bản nháp báo cáo đồ án đủ 7 chương.

- **Tài liệu dùng kèm:** trang Đánh giá học phần (quy định định dạng, cấu trúc báo cáo); Kế hoạch Agile (release burndown, Definition of Done của bản phát hành); giáo trình di động Chương 11 (triển khai backend và CSDL).
- **User story:** US-A07 (tình trạng hệ thống, mức cơ bản qua `/api/health`); toàn bộ phạm vi phát hành.
- **Thời lượng gợi ý:** 2 tiết trên lớp, báo cáo làm ở nhà.

### Chuẩn bị môi trường

- Thông tin từ bộ phận hỗ trợ: địa chỉ server, cách truy cập, cổng cho web và API, tên miền, HTTPS có hay chưa, công cụ chạy dịch vụ nền.
- Backend và CSDL của nhóm đã chạy trên server theo Chương 11 giáo trình di động.
- Node.js bản LTS trên server (cùng phiên bản chính với máy phát triển).

```bash
git checkout main && git pull
git checkout -b release/v1.0
```

### Các bước triển khai

**Bước 1. Cấu hình.** `output: 'standalone'`, `serverActions.allowedOrigins`, `COOKIE_SECURE`, `/api/health` (mục 11.2–11.3).

**Bước 2. Build thử trên máy.** Build và chạy bản standalone trên máy mình với biến môi trường giống server; mở `/api/health`.

**Bước 3. Triển khai.** Theo hướng dẫn của bộ phận hỗ trợ: chép bản build, đặt biến môi trường, đăng ký dịch vụ nền; mở CORS của API cho địa chỉ web.

**Bước 4. Kiểm tra.** Chạy danh sách 1–6 (mục 11.4.1), chụp ảnh có ngày giờ; lỗi nào phát sinh ghi vào board.

**Bước 5. README triển khai** theo mục 11.4.2.

**Bước 6. Bản nháp báo cáo.** Ghép và biên tập 7 chương theo mục 11.5; Chương 7 lấy số liệu từ board (mục 11.6); dùng Heading đánh số, Insert Caption, mục lục và danh mục hình tự động.
