## Bài tập hướng dẫn theo dự án LHU Food

**Nhiệm vụ:** khởi tạo dự án web LHU Food, kết nối thử API mẫu, lập phạm vi web và kế hoạch Sprint 1 của nhóm.

- **Tài liệu dùng kèm:** SRS mục 2.3 (kiến trúc), 2.4 và 10.2 (phân vai web/mobile), 4.2–4.5 (user story); Kế hoạch Agile (Product Backlog, Definition of Done).
- **User story:** chuẩn bị cho US-G01, US-G03; phân tích phạm vi US-A01…A07, US-S02…S07.
- **Thời lượng gợi ý:** 1,5 tiết trên lớp, phần kế hoạch hoàn thành ở nhà.

### Chuẩn bị môi trường

- Node.js bản LTS (`node -v`), Git, Visual Studio Code, trình duyệt Chrome hoặc Edge.
- Tài khoản GitHub của mỗi thành viên; một repo chung cho web của nhóm.
- Google Antigravity hoặc GitHub Copilot Chat đã đăng nhập.
- Địa chỉ API mẫu và tài khoản thử (thông báo trên Moodle).

```bash
npx create-next-app@latest lhu-food-web --ts --tailwind --eslint --app --import-alias "@/*"
cd lhu-food-web
git init && git add . && git commit -m "Khởi tạo dự án Next.js"
git branch -M main
git remote add origin <url-repo-của-nhóm>
git push -u origin main
```

### Các bước triển khai

**Bước 1. Chạy dự án.** `npm run dev`, mở `http://localhost:3000`. Ghi phiên bản Node.js và Next.js (`npx next --version`) vào README.

**Bước 2. Ba trang đầu tiên.** Tạo `app/page.tsx` (giới thiệu LHU Food), `app/menu/page.tsx` (tiêu đề "Thực đơn"), `app/admin/page.tsx` (tiêu đề "Trang quản trị") theo mục 1.2.2. Mỗi trang có một liên kết `Link` về trang chủ.

**Bước 3. Thử API mẫu.** Mở `<địa-chỉ-API-mẫu>/docs` trên trình duyệt, gọi thử `GET /categories` và `GET /products`. Ghi lại dạng dữ liệu trả về (tên trường, kiểu) vào `docs/api-notes.md`. Không gọi API từ mã ở bài này.

**Bước 4. AGENTS.md.** Tạo file quy ước theo mục 1.5.1, chép sang `.github/copilot-instructions.md`. Tạo `PROMPTS.md` với tiêu đề các cột: ngày, người, mục đích, prompt, kết quả đã sửa.

**Bước 5. Phạm vi web.** Lập bảng truy vết trang – user story – actor – sprint (mục 1.3.3) cho toàn bộ phạm vi bắt buộc, lưu ở `docs/pham-vi-web.md`.

**Bước 6. Kế hoạch Sprint 1.** Viết Sprint Goal; chọn story từ Product Backlog dùng chung; ước lượng story point; tạo board (GitHub Projects hoặc Jira) với 4 cột và gán người phụ trách cho mỗi thẻ.

### Vibe coding

```text
Đọc AGENTS.md. Dự án dùng Next.js App Router (thư mục app/), TypeScript, Tailwind CSS.
Tạo trang app/menu/page.tsx là Server Component, hiển thị tiêu đề "Thực đơn"
và một danh sách 6 món giả (tên, giá dạng "35.000 đ") dùng lưới Tailwind
1 cột trên điện thoại, 3 cột từ màn hình md. Không dùng "use client",
không dùng thư mục pages/, không cài thêm thư viện.
```

Kiểm tra kết quả AI:

- Không có thư mục `pages/`, không có `getServerSideProps` hay `getStaticProps`.
- Trang không có `"use client"`, không dùng `useState` (trang này chưa cần tương tác).
- Giá định dạng bằng `toLocaleString('vi-VN')`, có chữ "đ".
- Thu nhỏ trình duyệt để thấy lưới đổi từ 3 cột về 1 cột.

### Kiểm tra và hoàn thành
