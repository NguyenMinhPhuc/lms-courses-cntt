## Bài tập hướng dẫn theo dự án LHU Food

**Nhiệm vụ:** thay dữ liệu giả bằng dữ liệu thật từ API mẫu cho thực đơn, chi tiết món và danh sách quầy; xử lý trạng thái tải, lỗi, rỗng; viết và chạy test case; hoàn thành Checkpoint Sprint 1.

- **Tài liệu dùng kèm:** SRS mục 4.7 (tiêu chí US-G01, G02, G03), mục 8 (định dạng API); Kế hoạch Agile (Definition of Done, Sprint Review).
- **User story:** US-G01, US-G02, US-G03; US-G06 phần web (danh sách quầy).
- **Thời lượng gợi ý:** 1,5 tiết trên lớp, 1 tiết Checkpoint.

### Chuẩn bị môi trường

```bash
git checkout main && git pull
git checkout -b feature/menu-api
npm install server-only
```

Tạo `.env.local` với `API_URL` của API mẫu; kiểm tra `.gitignore` có dòng `.env*`. Chép `.env.local` thành `.env.example` với giá trị giả để thành viên khác biết cần biến gì.

### Các bước triển khai

**Bước 1. Kiểu và hàm gọi API.** Tạo `lib/types.ts` theo Swagger của API mẫu và `lib/api.ts` (mục 3.2.2).

**Bước 2. Thực đơn.** Viết lại `/menu` theo mục 3.2.3: danh mục, lọc theo danh mục, tìm kiếm qua `searchParams`, trạng thái rỗng.

**Bước 3. Chi tiết món.** `/product/[id]` gọi `GET /products/:id`; API trả 404 thì gọi `notFound()`; hiện "Hết món" khi hết hàng; ảnh rỗng thì dùng ảnh thay thế.

**Bước 4. Tải và lỗi.** Thêm `loading.tsx` và `error.tsx` cho `(shop)/menu` và `(shop)/product/[id]`. Thử đổi `API_URL` sai để thấy giao diện lỗi.

**Bước 5. Quầy.** Chuyển `/counters` sang `GET /counters`, chọn thời gian `revalidate` và ghi lý do trong `docs/quyet-dinh-cache.md`.

**Bước 6. Test case.** Viết bảng test case TC-01…TC-05 (mục 3.5.1) và các test case cho story nhóm làm trong Sprint 1, lưu `docs/test/sprint-1.md`, chạy và ghi kết quả.

**Bước 7. Checkpoint Sprint 1.** Demo; nộp bảng ánh xạ, sơ đồ chức năng, sitemap, test case có kết quả, báo cáo sprint 1 (mục 3.5.2) và kế hoạch Sprint 2 trên board.

### Vibe coding

```text
Đọc AGENTS.md, lib/types.ts và lib/api.ts. Viết lại app/(shop)/menu/page.tsx là Server Component async:
searchParams kiểu Promise<{ category?: string; q?: string }>, gọi song song
apiGet<Category[]>('/categories', 300) và apiGet<Product[]>('/products?...', 30) bằng Promise.all.
Form tìm kiếm là form GET thường (không "use client"). Có trạng thái rỗng "Không tìm thấy món phù hợp".
KHÔNG dùng useEffect, KHÔNG gọi fetch từ trình duyệt, KHÔNG dùng getServerSideProps.
```

Kiểm tra kết quả AI:

- Không có `useEffect` + `fetch` để lấy dữ liệu (cách của React SPA); dữ liệu được lấy trong Server Component.
- `searchParams` được `await`; hai API gọi song song chứ không lần lượt.
- `lib/api.ts` có `import 'server-only'`; không component nào có `"use client"` import nó.
- Hỏi AI: "Liệt kê các trường hợp lỗi có thể xảy ra ở trang này" rồi đối chiếu với test case của bạn.
