## Bài tập hướng dẫn theo dự án LHU Food

**Nhiệm vụ:** xây giỏ hàng, form đăng ký và trang đặt món gọi API mẫu; thêm bảng giá trị biên và test case cho các form; đánh dấu Server/Client trên sơ đồ thành phần.

- **Tài liệu dùng kèm:** SRS mục 4.7 (tiêu chí US-G04, C01, C02, C04), mục 6 (quy tắc nghiệp vụ), mục 8 (định dạng lỗi của API); Kế hoạch Agile (story Sprint 2).
- **User story:** US-C01, US-C02, US-C04, US-G04.
- **Thời lượng gợi ý:** 2 tiết trên lớp.

### Chuẩn bị môi trường

```bash
git checkout main && git pull
git checkout -b feature/cart-forms
npm install zustand zod react-hook-form @hookform/resolvers
npx shadcn@latest add input label form sonner
```

Lấy access token của tài khoản customer ở `/docs` của API mẫu (POST `/auth/login`), đặt vào `.env.local` với tên `DEV_ACCESS_TOKEN`. Token hết hạn sau 15 phút.

### Các bước triển khai

**Bước 1. Store giỏ hàng.** `lib/cart-store.ts` theo mục 4.2.2; `AddToCartButton` trên trang chi tiết món; `CartBadge` trên header (mục 4.3.2).

**Bước 2. Trang giỏ hàng.** `/cart` hiển thị từng dòng, nút tăng/giảm/xóa, tổng tiền; giỏ rỗng hiện "Giỏ hàng đang trống" và liên kết về thực đơn.

**Bước 3. Đăng ký.** `lib/schemas.ts`, `register/actions.ts`, `register/register-form.tsx` theo mục 4.4; đủ 4 ô có nhãn và lỗi tiếng Việt.

**Bước 4. Đặt món.** `lib/session.ts` tạm, `checkout/actions.ts` theo mục 4.5.1; trang `/checkout` có ô ghi chú, nút Đặt món vô hiệu khi đang gửi, thành công thì xóa giỏ.

**Bước 5. Test case.** Bảng TC-11…TC-17 (mục 4.5.2) và test case cho form nhóm phụ trách, lưu `docs/test/sprint-2-form.md`, chạy và ghi kết quả.

**Bước 6. Cập nhật phân tích.** Trên cây component của các trang, đánh dấu S/C và lý do (mục 3.1.2).

### Vibe coding

```text
Đọc AGENTS.md và lib/schemas.ts. Tạo app/(shop)/register/register-form.tsx là Client Component
dùng react-hook-form với zodResolver(registerSchema). Mỗi ô (fullName, email, password, confirm)
có <label>, lỗi hiện ngay dưới ô bằng tiếng Việt lấy từ schema. Khi gửi, gọi registerAction(data)
từ ./actions (Server Action); lỗi từ server hiện trong <p role="alert">. Nút vô hiệu khi isSubmitting.
KHÔNG gọi fetch tới API từ component này; KHÔNG viết lại quy tắc kiểm tra ngoài schema.
```

Kiểm tra kết quả AI:

- Quy tắc kiểm tra chỉ nằm trong `lib/schemas.ts`; AI hay viết thêm `if (password.length < 8)` rải rác trong component.
- Server Action gọi `safeParse` lại trên server, không tin dữ liệu từ form.
- Không lưu giá hay token vào `localStorage`; không gọi API từ trình duyệt.
- Thử tắt JavaScript (DevTools → Settings → Disable JavaScript) và gửi form: dữ liệu sai vẫn bị từ chối hoặc form không gửi được.
