## Bài tập hướng dẫn theo dự án LHU Food

**Nhiệm vụ:** làm đăng nhập bằng tài khoản API mẫu, lưu token trong cookie `httpOnly`, bảo vệ khu quản trị theo ba lớp, đăng xuất có thu hồi token; lập ma trận phân quyền và chạy test case truy cập trái phép.

- **Tài liệu dùng kèm:** SRS mục 4.7 (tiêu chí US-G05, C13, S01, A01), mục 6 (BR-03), mục 8 (các endpoint `/auth`, `/users/me`).
- **User story:** US-G05, US-C13, US-S01.
- **Thời lượng gợi ý:** 1,5 tiết trên lớp.

### Chuẩn bị môi trường

```bash
git checkout main && git pull
git checkout -b feature/auth
npm install jose
npx next --version     # 16.x: dùng proxy.ts; 15.x: dùng middleware.ts
```

Chuẩn bị ba tài khoản thử của API mẫu (customer, staff, admin). Xóa `DEV_ACCESS_TOKEN` khỏi `.env.local` sau khi đăng nhập thật chạy được.

### Các bước triển khai

**Bước 1. Cookie phiên.** Thay `lib/session.ts` bằng bản mục 5.2.3.

**Bước 2. Đăng nhập.** `login/actions.ts` (mục 5.2.4) và trang `/login` dùng `useActionState`, có ô ẩn `next` lấy từ `searchParams`.

**Bước 3. Proxy.** Tạo `proxy.ts` (hoặc `middleware.ts`) theo mục 5.4.1 và trang `/forbidden` thân thiện.

**Bước 4. Data Access Layer.** `lib/dal.ts` (mục 5.4.3); gọi `requireRole` trong mọi trang `admin/*` và trong Server Action `placeOrder`.

**Bước 5. Header và đăng xuất.** Header hiện tên người dùng, menu theo vai trò, nút Đăng xuất gọi `logoutAction` (mục 5.5.3) và xóa giỏ hàng.

**Bước 6. Ma trận và test case.** Lập ma trận phân quyền cho web nhóm (`docs/ma-tran-phan-quyen.md`); chạy TC-21…TC-28 và test cho mọi ô ✘, ghi kết quả.

### Vibe coding

```text
Đọc AGENTS.md, lib/session.ts, lib/dal.ts. Tạo trang app/admin/products/page.tsx là Server Component:
dòng đầu gọi await requireRole('admin') từ lib/dal; lấy danh sách món bằng apiAuth từ lib/api.
Tạo trang app/forbidden/page.tsx hiển thị "Bạn không có quyền truy cập trang này" và liên kết về trang chủ.
KHÔNG đọc token trong Client Component, KHÔNG lưu token vào localStorage,
KHÔNG kiểm tra quyền bằng cách ẩn nút trên giao diện thay cho requireRole.
```

Kiểm tra kết quả AI:

- AI hay lưu token trong `localStorage` hoặc context React; phải nằm trong cookie `httpOnly` và chỉ đọc ở server.
- AI hay chỉ kiểm tra quyền trong `layout.tsx` hoặc chỉ trong `proxy.ts`; mỗi trang và Server Action nhạy cảm phải có `requireRole`.
- Kiểm tra `next` được lọc trước khi `redirect` (chặn open redirect).
- Thử TC-26 trong DevTools: `document.cookie` không được thấy `access_token`.

### Kiểm tra và hoàn thành

- ☐ Đăng nhập được bằng ba vai trò; mỗi vai trò về đúng trang mặc định.
- ☐ Customer và staff không vào được trang chỉ dành cho admin, kể cả gõ thẳng URL.
- ☐ Đăng xuất thu hồi refresh token, xóa giỏ hàng.
- ☐ `docs/ma-tran-phan-quyen.md` có ma trận và kết quả test case cho mọi ô ✘.
