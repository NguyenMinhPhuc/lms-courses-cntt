Cách import vào Moodle (learn.lhu.edu.vn)

  1. Vào khóa học → Question bank → Import.
  2. Chọn File format: Aiken format.
  3. Chọn Category để chứa câu hỏi, ví dụ Quiz Bài 01.
  4. Kéo thả file .txt vừa tải (mã hóa UTF-8) → Import → kiểm tra số câu Moodle báo đã nhận.
  5. Tạo hoạt động Quiz, thêm câu hỏi từ Category, rồi gửi link quiz để điền vào bài học.
