Mô tả: Học phần hướng dẫn sinh viên xây dựng ứng dụng web full-stack bằng Next.js (App Router) cho dự án LHU Food, dùng chung đề tài và dữ liệu với học phần di động: trang quản trị và màn hình quầy thời gian thực là bắt buộc, web đặt món cho khách ở mức cơ bản. Sprint 1–2 dùng API mẫu của giảng viên; Sprint 3–4 nhóm tự xây module quản trị trên backend của nhóm, truy cập SQL Server bắt buộc qua stored procedure. Sinh viên luyện tập phân tích thành phần chức năng, kiểm thử theo yêu cầu, viết báo cáo đúng định dạng và lập kế hoạch công việc theo sprint.

Kết quả cần đạt: Mỗi nhóm nộp ứng dụng web chạy trên Windows Server của Khoa, kết nối backend dùng chung với ứng dụng di động, kèm báo cáo đồ án (phân tích thành phần, kiểm thử, kế hoạch và tiến độ) đúng quy định định dạng và báo cáo vai trò của từng thành viên.

2.3. Công nghệ sử dụng

  • Ứng dụng web: Next.js (App Router) + TypeScript, Tailwind CSS + shadcn/ui, React Hook Form + Zod, TanStack Table, Recharts, Socket.IO client.
  • Dữ liệu: Next.js không kết nối SQL Server trực tiếp; mọi dữ liệu đi qua backend API. Backend chỉ gọi stored procedure trên Microsoft SQL Server.
  • Backend: Sprint 1–2 dùng API mẫu LHU Food của giảng viên; Sprint 3–4 backend của nhóm (khuyến khích NestJS dùng chung với đồ án di động).
  • Kiểm thử: Vitest, Testing Library, Playwright; Lighthouse cho hiệu năng và accessibility.
  • Quản lý công việc: GitHub Projects hoặc Jira; công cụ AI Google Antigravity, GitHub Copilot Chat; thiết kế Figma, draw.io.

💡 3. Cách học & quy tắc làm việc ▼

🧩 Học theo dự án (PBL), dùng chung đề tài với học phần di động

Nhóm 4–5 sinh viên phát triển phần web của cùng đề tài với đồ án di động, suốt 4 sprint. Cuối mỗi sprint (buổi 03, 06, 09) nhóm demo, nộp sản phẩm phân tích, kiểm thử, báo cáo sprint và kế hoạch sprint sau. Demo Day buổi 12 tổ chức chung với học phần di động.

🤖 Vibe coding có kiểm soát

  • Được dùng Google Antigravity và GitHub Copilot Chat để sinh mã; mỗi Pull Request kèm prompt chính (ghi trong PROMPTS.md).
  • Không hiểu thì không merge: người tạo PR phải giải thích được mọi đoạn mã khi được hỏi.
  • Mỗi nhóm có AGENTS.md và .github/copilot-instructions.md mô tả kiến trúc Next.js App Router và quy ước dự án để AI sinh mã nhất quán.
  • Commit nhỏ, mỗi tính năng một nhánh, review chéo trước khi merge; công việc được giao và theo dõi trên board (GitHub Projects/Jira).

🗄️ Quy tắc dữ liệu

Ứng dụng Next.js không kết nối SQL Server và không chứa câu SQL. Mọi dữ liệu đi qua backend API; backend chỉ gọi stored procedure có tham số. Token đăng nhập lưu trong cookie httpOnly, không lưu trong localStorage.

Laptop cài Node.js (bản LTS), VS Code, Git; tài khoản GitHub; trình duyệt Chrome hoặc Edge; đọc trước phần web trong SRS LHU Food (actor quản lý và nhân viên, user story [W] và [M+W]).
