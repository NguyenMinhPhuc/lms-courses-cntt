Quy trình soạn bài giảng
với Claude Code

Từ đề cương hoặc tài liệu thô đến một học phần hoàn chỉnh trên Moodle: bài học accordion, slide PowerPoint, ngân hàng câu hỏi Aiken, đề cương và rubric. Claude làm phần soạn thảo và định dạng; giảng viên quyết định nội dung và duyệt kết quả.

Chỉ có outline / đề cương

Claude tự soạn kiến thức chuyên môn. Bắt buộc duyệt dàn ý ở bước 3 trước khi viết bài, và đọc kỹ nội dung ở bước 6.

1

Chuẩn bị tài liệu (giảng viên)

Tạo thư mục học phần ở gốc repo, tên viết thường không dấu, ví dụ nhap-mon-lap-trinh/. Chép tài liệu vào nhap-mon-lap-trinh/tai-lieu/.

  • Thông tin hành chính: tên môn, mã môn, số tín chỉ (tiết LT/TH), số buổi, giảng viên, tỷ trọng điểm.
  • Nội dung: outline hoặc đề cương chi tiết, CLO, danh sách chủ đề theo buổi.
  • Nếu có: slide, giáo trình, bài tập, rubric (PDF, DOCX, PPTX đều được).
  • Nếu có: link video YouTube, link quiz/nộp bài trên Moodle.
Thông tin nào không có, Claude sẽ hỏi lại hoặc để dạng {{LINK_...}}, không tự bịa. Đưa đủ thông tin hành chính ngay từ đầu thì về sau đỡ phải sửa.
2

Giao việc cho Claude

Mở VS Code tại thư mục repo, mở Claude Code và gõ yêu cầu. Câu lệnh có nhắc tới "soạn học phần" hay "bài giảng" sẽ tự kích hoạt skill lms-lecture-builder.

Mẫu A: chỉ có outline/đề cương

Soạn học phần Nhập môn lập trình vào thư mục nhap-mon-lap-trinh.
Hiện chỉ có đề cương trong nhap-mon-lap-trinh/tai-lieu/de-cuong.docx, chưa có slide.
Mã môn 1xxxxx, 3 TC (30 LT - 30 TH), 10 buổi, giảng viên ThS. Nguyễn Văn A.
Đánh giá: quá trình 30%, thực hành 30%, cuối kỳ 40%.
Ngôn ngữ dùng trong môn: Python. Có làm slide.
Làm dàn ý chi tiết trước để tôi duyệt.

Mẫu B: đã có slide/giáo trình

Soạn học phần Cơ sở dữ liệu vào thư mục co-so-du-lieu từ slide và giáo trình
trong co-so-du-lieu/tai-lieu/. Mã môn 1xxxxx, 3 TC (30 LT - 30 TH), 9 buổi.
Làm bước 1–3 (course.json, đề cương, đánh giá) trước để tôi xem.
3

Duyệt dàn ý chi tiết (bắt buộc khi chỉ có outline)

Claude tạo file dan-y-chi-tiet.md rồi dừng lại chờ bạn. Mỗi bài trong dàn ý gồm: CLO liên quan, mục tiêu, 4 ý chính kèm ví dụ dự kiến, hoạt động trên lớp, bài tập, số slide dự kiến và các điểm cần bạn xác nhận.

Bạn xem từng bài: phạm vi và độ sâu đã đúng chưa, ví dụ có phù hợp sinh viên không, có trùng lặp với môn khác không. Sửa thẳng trong file hoặc trả lời Claude, ví dụ:

Bài 4 bỏ phần đệ quy, chuyển sang bài 7. Dự án xuyên suốt đổi thành quản lý điểm sinh viên. Duyệt, soạn tiếp.

Sửa ở mức dàn ý nhanh hơn nhiều so với sửa cả bài đã viết xong.

4

Soạn bài học theo đợt

Nên giao 2–3 bài mỗi lần để duyệt kịp, ví dụ: "Soạn bài 1–3 kèm quiz." Với mỗi bài, Claude tạo:

FileNội dung
bai-XX.md4 khối accordion: 📘 Tổng quan · 📚 Học liệu (lý thuyết, ví dụ) · 💡 Hoạt động & thực hành · 🆘 Trợ giúp. Đây là bản dán vào Moodle.
bai-XX.htmlTrang xem trên portal, sinh tự động từ .md
quiz/quiz-bai-XX-aiken.txt10 câu trắc nghiệm, đáp án đã chia đều A/B/C/D. Dùng cho 2 việc: import Moodle và luyện tập trực tiếp ở cuối trang bài học.

Muốn sửa thì nói với Claude, ví dụ "Bài 2 thêm ví dụ vòng lặp while". Trang .html và file quiz tổng hợp được build lại tự động.

Sinh viên: luyện tập trên web
Cuối mỗi trang bài học có khung Luyện tập trắc nghiệm. Câu hỏi và phương án được xáo mỗi lần làm. Nộp bài chỉ báo số câu đúng / sai / bỏ trống, không hiện đáp án, không lưu kết quả.
Giảng viên: tải file để import
Trên thẻ học phần ở portal, bấm Ngân hàng câu hỏi để tải từng file Aiken hoặc file tổng hợp. Trang này có đáp án, không gửi link cho sinh viên.
5

Làm slide bài giảng

Slide được làm từ bài học đã duyệt, nên nội dung slide, trang Moodle và quiz luôn khớp nhau. Mỗi bài có 2 file trong thư mục Slides/:

bai-XX.markdown

Ghi chú slide: mỗi slide gồm tiêu đề, nội dung chính, ví dụ, hoạt động và ghi chú giảng viên. Đây là file nguồn để sửa.

bai-XX.pptx

Slide PowerPoint 16:9 theo màu LHU, sinh tự động từ file .markdown. Ghi chú giảng viên nằm trong Speaker Notes.

Làm slide cho bài 1–3.
Slide 5 bài 2 nhiều chữ quá, tách làm 2 slide.
Không sửa trực tiếp file .pptx, vì lần build sau sẽ ghi đè. Cần chỉnh thiết kế riêng cho một buổi thì lưu thành file khác, ví dụ bai-02-final.pptx.
6

Duyệt nội dung (giảng viên, phần quan trọng nhất)

Script chỉ kiểm tra được định dạng. Phần nội dung bạn phải tự đọc lại:

  • Kiến thức: định nghĩa, số liệu, code mẫu có chính xác không; code có chạy được không.
  • Quiz: đáp án đúng về chuyên môn; không có câu đánh đố hoặc mơ hồ.
  • Slide: mở file .pptx xem chữ có tràn khung không.
  • Link: điền link thật thay cho {{LINK_...}}, sửa thẳng file hoặc gửi danh sách cho Claude.
7

Kiểm tra tự động

Claude tự chạy bước này khi soạn xong. Bạn cũng có thể tự chạy trong terminal tại thư mục repo:

uv run python validate-course.py nhap-mon-lap-trinh
[LỖI] Phải sửa: thiếu file, sai cấu trúc accordion, quiz sai định dạng Aiken, trang .html/.pptx chưa build lại.
[CẢNH BÁO] Nên xem: link còn để placeholder, link chép nhầm từ template, đáp án dồn vào một chữ cái.

Xem thử trên portal: chạy start-portal.bat, học phần mới sẽ hiện trên trang danh mục.

8

Đưa lên Moodle (learn.lhu.edu.vn)

  1. Bài học: mở bai-XX.md, chép toàn bộ → trên Moodle thêm Page hoặc Label → bật chế độ HTML (<>) → dán → Lưu.
  2. Đề cương, đánh giá: làm tương tự với thong-tin-hoc-phan.md và danh-gia-hoc-phan.md.
  3. Quiz: tải file từ trang Ngân hàng câu hỏi của học phần → trên Moodle vào Question bank → Import → Aiken format → chọn Category → kéo thả quiz-bai-XX-aiken.txt → Import. Muốn nhập một lần thì dùng file tong-hop-N-cau-quiz-aiken.txt.
  4. Slide: tải Slides/bai-XX.pptx lên mục học liệu của buổi học.
  5. Điền link: tạo quiz/assignment trên Moodle xong thì gửi link cho Claude: "Link quiz bài 1 là https://learn.lhu.edu.vn/mod/quiz/view.php?id=...". Claude sẽ điền vào bài học và build lại.

Tra cứu nhanh: lệnh và file

Khi làm việc với Claude Code, hook tự chạy các lệnh build ngay sau khi Claude sửa file. Bạn chỉ cần tự chạy khi sửa file bằng tay.

Cấu trúc một thư mục học phần

nhap-mon-lap-trinh/
├── course.json                 # Mã môn, tín chỉ, giảng viên… (bật coursePages, slides)
├── index.html                  # Landing page (portal nhận diện học phần qua file này)
├── README.md                   # Tổng quan học phần
├── dan-y-chi-tiet.md           # Dàn ý (khi soạn từ outline)
├── thong-tin-hoc-phan.md/.html # Đề cương
├── danh-gia-hoc-phan.md/.html  # Đánh giá & rubric
├── bai-01.md/.html … bai-NN    # Bài học (.md dán Moodle, .html xem web)
├── Slides/bai-01.markdown/.pptx
├── quiz/quiz-bai-01-aiken.txt … tong-hop-N-cau-quiz-aiken.txt
├── quiz/index.html             # Trang tải file Aiken (giảng viên)
└── tai-lieu/                   # Tài liệu gốc của giảng viên

Nguyên tắc cần nhớ

  • Chỉ sửa file nguồn: .md, Slides/*.markdown, file quiz. Không sửa bai-XX.html và .pptx, vì chúng được sinh tự động và sẽ bị ghi đè.
  • Một nguồn nội dung: sửa kiến thức thì sửa bai-XX.md trước, rồi yêu cầu Claude cập nhật slide và quiz theo.
  • Không bịa: Claude không tự đặt link, mã môn hay số liệu về Khoa. Thông tin chưa có sẽ được để dạng {{...}} để bạn điền.
  • Giảng viên chịu trách nhiệm nội dung: luôn duyệt dàn ý, bài học và đáp án quiz trước khi đưa cho sinh viên.
