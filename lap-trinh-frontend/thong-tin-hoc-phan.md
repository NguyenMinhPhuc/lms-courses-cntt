        <p><strong>Mô tả tóm tắt học phần:</strong></p>
        <p style="text-align: justify; color: #333;">
            Học phần trang bị cho sinh viên quy trình xây dựng một ứng dụng web Front-End hoàn chỉnh, đi từ bản vẽ Wireframe đến sản phẩm chạy thật trên Internet. Chúng ta sử dụng Next.js App Router, TypeScript ở chế độ strict, SCSS Module và Ant Design v5 để dựng giao diện, quản lý state bằng React Hooks, kết nối RESTful API có sẵn (Swagger), xử lý form với React Hook Form + Zod, sau đó triển khai CI/CD lên Vercel và tối ưu SEO, Lighthouse.
        </p>
        <p style="text-align: justify; color: #333;">
            Điểm khác biệt của học phần là <strong>Vibe Coding</strong>: các bạn dùng trợ lý AI (Cursor, GitHub Copilot, v0.dev, ChatGPT/Claude) để sinh khung code, nhưng luôn phải đọc, hiểu, sửa lỗi và chịu trách nhiệm với từng dòng code mình đưa vào repository. Toàn bộ kiến thức được gắn vào một dự án duy nhất là <strong>Smart Event Hub</strong>, do nhóm 3-4 sinh viên phát triển liên tục qua 12 buổi và bảo vệ tại vòng Hackathon cuối kỳ.
        </p>
