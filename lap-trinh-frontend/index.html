Chuẩn đầu ra học phần

Mỗi chuẩn đầu ra gắn với một chỉ số đo lường (PI) theo khung ABET và được kiểm tra qua sản phẩm cụ thể.

CLO1PI 1.4

Phân tích yêu cầu, mô hình hóa UI/Wireframe và tổ chức kiến trúc component cho ứng dụng web.

CLO2PI 2.3

Xây dựng ứng dụng Front-End với Next.js, TypeScript, SCSS/Ant Design, quản lý state, kết nối REST API, dùng AI có kiểm soát.

CLO3PI 3.1

Viết báo cáo kỹ thuật, thuyết trình và demo sản phẩm rõ ràng, chuyên nghiệp.

CLO4PI 5.1

Làm việc nhóm với Git (branch, PR, review), triển khai CI/CD lên Vercel, tối ưu SEO và hiệu năng.

Câu hỏi thường gặp

Dùng AI viết code có bị xem là gian lận không?

Không, học phần khuyến khích Vibe Coding. Điều kiện là các bạn phải đọc hiểu, kiểm tra kiểu dữ liệu, sửa lỗi và giải thích được đoạn code đó khi giảng viên hỏi phản biện. Code chép nguyên mà không giải thích được sẽ bị trừ điểm cá nhân.

Cần chuẩn bị gì trước buổi 1?

Cài VS Code, Node.js bản LTS, Git và tạo tài khoản GitHub. Cài thêm extension Cursor AI hoặc GitHub Copilot, sau đó xem video về SCSS Mixin và TypeScript Interface/Type trên LMS.

Nhóm làm dự án gồm bao nhiêu người?

Mỗi nhóm 3–4 sinh viên, cùng làm một repository với các nhánh main, dev và feature/*. Mỗi thành viên phải có commit riêng để làm minh chứng đóng góp.

Backend API lấy ở đâu?

Giảng viên cung cấp RESTful API Backend kèm tài liệu Swagger UI. Trước buổi 8 các bạn dùng mock data JSON, từ buổi 8 chuyển sang gọi API thật qua biến môi trường NEXT_PUBLIC_API_URL.
