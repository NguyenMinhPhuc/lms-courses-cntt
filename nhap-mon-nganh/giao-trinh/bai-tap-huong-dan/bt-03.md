## Bài tập hướng dẫn: Hồ sơ GitHub đầu tiên

**Nhiệm vụ:** tạo tài khoản GitHub chuyên nghiệp và kho mã `gioi-thieu-ban-than` có README viết bằng Markdown giới thiệu bản thân và mục tiêu nghề nghiệp.

- **Kiến thức dùng:** các vai trò nghề nghiệp (mục 3.1.2), hồ sơ năng lực trên GitHub (mục 3.4.1), đọc tin tuyển dụng (mục 3.4.3).
- **Thời lượng gợi ý:** 60 phút trên lớp.
- **Sản phẩm nộp:** đường link kho mã lên LMS.

### Chuẩn bị

- Email sinh viên để đăng ký GitHub (dễ nhận các chương trình ưu đãi cho sinh viên).
- Một tin tuyển dụng Fresher/Junior cho vị trí bạn quan tâm.

### Các bước thực hiện

1. Đăng ký tài khoản GitHub; tên tài khoản gần với tên thật, dễ đọc; bật xác minh 2 bước.
2. Cập nhật hồ sơ: ảnh đại diện, tên, mô tả ngắn, trường học.
3. Tạo kho mã công khai `gioi-thieu-ban-than`, chọn tạo sẵn tệp `README.md`.
4. Viết README bằng Markdown gồm: tiêu đề có tên bạn; đoạn giới thiệu; vị trí công việc mong muốn; bảng công nghệ đã biết và sẽ học; danh sách kỹ năng lấy từ tin tuyển dụng đã chọn.
5. Commit thay đổi với thông điệp rõ ràng, ví dụ `Thêm giới thiệu và mục tiêu nghề nghiệp`.
6. (Khuyến khích) Tạo thêm kho mã trùng tên tài khoản để hiển thị README ở trang hồ sơ.

### Dùng AI có trách nhiệm

- Có thể nhờ AI hướng dẫn cú pháp Markdown; không để AI viết thay phần giới thiệu và mục tiêu.
- Không đưa số điện thoại, địa chỉ nhà, số căn cước lên README công khai.

### Hoàn thành khi

- Kho mã công khai truy cập được, README hiển thị đúng định dạng (tiêu đề, danh sách, bảng).
- Có ít nhất 2 commit với thông điệp rõ ràng.
- Danh sách kỹ năng gắn với tin tuyển dụng có ghi nguồn (tên trang, ngày xem).
